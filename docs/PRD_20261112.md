### 1.1 FR-D1 细项

1. 设置页入口：按钮样式与「检查更新」同款（深底键帽、蓝字、非焦点无常亮——上游决策 44 高亮收敛口径；焦点态 = `accent-wash` 上界底 + `border-accent` 描边，上游 6.4 口径）。
2. 设置页调试区移除：顶部 `test_input_area`（测试输入框 + 填入示例文本 + 全选）整体移除；移除后页面布局与既有功能（品牌区、版本信息卡、检查更新三态、面包屑、底部提示）回归不变。
3. 测试打字页：承载测试输入框（占位文案「测试输入框：用于键盘与上屏验收」）、「填入示例文本」「全选」按钮；BACK 返回设置页；无 LAUNCHER 入口（不从桌面可达）。
4. 门控：沿用现行调试区实现的门控口径（debug 构建可见性等），开工时核对并如实记录于 issue。
5. 无障碍：全部可交互元素无障碍标注齐全，焦点与状态满足可读性要求（上游批次第 8 章口径）。

## 4. 验收标准

1. 模拟器（API 34）：设置页出现「测试打字」按钮，非焦点无常亮、聚焦有高亮（T57 收敛口径）；点击/OK 进入测试打字页。
2. 测试打字页：测试输入框、「填入示例文本」「全选」可用；键盘唤起、组合/上屏验收链路不回归。
3. 设置页移除调试区后布局与既有设置页功能回归（检查更新三态等）。
4. 无障碍：全部可交互元素标注齐全，焦点与状态满足可读性要求。
5. 单测全绿（`--rerun-tasks` 强制实跑口径）。
6. 真机复验（MiTV4；模拟器验证成功后询问户主是否执行）。
