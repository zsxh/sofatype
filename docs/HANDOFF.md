# Handoff · 开发交接文档

给 agent 和人看的开发注意事项。记录每次版本更新的详细改动与踩过的坑。

细节出处：

- 简版差异：根目录 `CHANGELOG.md`。
- 实机参数与坑：`docs/devices/` 设备档案。
- 原则与红线：`AGENTS.md`。

本文档不重复上述内容。具体问题引用对应文档，不在本文展开。

## 维护约定（每次版本更新都要做）

1. `CHANGELOG.md` 加一条简短记录：新增 / 变更 / 修复。
2. 本文追加一节「版本记录」：改动、原因、坑。
3. 实机新坑写入对应设备档案。同一事实只在设备档案维护，本文只写指向。
4. 需求 / 设计变更追加到 PRD 第 12 章。编号顺延，不重排。
5. 两者只记代码 / 软件层面的变更；纯文档调整不记。
