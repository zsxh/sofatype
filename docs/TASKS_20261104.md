## 1. 拆分原则

1. 每个任务是完整闭环：编译 → 安装 → 运行 → 按验收点走查。
2. 模拟器（API 34）做逻辑回归。真机验收收敛到里程碑级任务。模拟器不覆盖性能预算、微信内核、真实遥控器。
3. 优先级：P0 先行，P1 随 M3 落地，P2 全部不做（见第 7 节）。
4. 「已完成」的唯一标准是真机验证（AGENTS.md）。汇报区分「已实现」与「真机已验证」。
