## 目标

基线设备（小米电视4，Android 6.0.1 / API 23）「发现新版 → 下载 → 安装确认 → 未知来源授权」全链可用，不崩溃。

## 改动

修复 `UpdateHttp.downloadToFile` 的 API 级别检查缺失：`getContentLengthLong()` 为 API 24+ 方法，minSdk 23 无此方法。参考方向（归 dev 拍板，不预设）：改 int 版 `getContentLength()`（2GB 内等价）或 `Build.VERSION` 门控。

## 原因

T27 首版终验真机发现（2026-11-09，Round 1）：Android 6.0.1 点「下载更新」100% 触发 `NoSuchMethodError`（UpdateHttp.kt:66 ← SettingsActivity.kt:214），下载线程未捕获 → 进程死亡 → 设置页 Force finish → default_input_method 回退（设备档案坑 5/9 连锁）。严重程度 Blocker（基线设备核心链路完全不可用）；T21 验收走模拟器 API 34 未暴露，属 API 级别检查缺失。T21 真机挂账「未知来源」授权链路被此阻断未验。
