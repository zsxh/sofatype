## 背景

2026-11-24 户主会话拍板：仓库已推 GitHub（T100 直发 v0.2.1 Release），应用内「检查更新」要求能够从 release 获取最新版；mock 通道保留用于 debug 测试（户主口径「mock 在测试 debug 时使用，release 需要从真实地址获取」）。现状：`strings.xml` 的 `update_endpoint_url` 为空串（历史口径仅 mock 走查、由 debug 源集 `UpdateMockReceiver` 显式注入），release 构建检查更新只会报 endpoint 为空。

## 需求与口径

1. **生产 endpoint**：`update_endpoint_url` = `https://api.github.com/repos/zsxh/sofatype/releases/latest`（GitHub Releases latest API，返回最新已发布 release 单对象）。debug 构建的 mock 注入通道（`UpdateMockReceiver` → `UpdateEndpoint.setDebugOverride`，进程内存覆写）保持不变，mock 仍为 debug 测试专用。
2. **解析器形状兼容**：`UpdateReleaseParser` 顶层兼容两种形状——既有数组（`/releases` 列表形，mock 与 GitHub 列表接口沿用）与单对象（`/releases/latest` 形）。解析字段与跳过规则不变（跳过 draft/prerelease/空 tag；必须有 `.apk` 资产）。
3. **版本判定不变**：`UpdateVersion.compare` 既有口径（tag 去 `v` 前缀、数字段比较；release tag 新于当前 versionName → Newer，否则 UpToDate）。
4. **网络口径**：匿名 GET、无设备标识（User-Agent `sofatype-ime-update` 沿用）；GitHub API 匿名限流 60 次/时/IP，检查更新为设置页手动低频操作，限流偶发 403 走既有「检查失败可重试」态（决策 39 口径不变）。
5. **前置依赖**：仓库可见性须为 Public（匿名可访问），否则电视端不可达——户主拍板见「追加补充」。

## 方案评估

预评（实施前）：

- 影响范围：`app/src/main/res/values/strings.xml`（endpoint）、`UpdateReleaseParser.kt`（顶层单对象分支，~10 行）、`UpdateReleaseParserTest.kt`（新增 latest 形状用例）、mock README 与 DEVELOP.md 说明同步。检查链其余（HTTP / 下载 / 安装 / 失败重试）零改动。
- 回归面：mock 走查链（debug 注入 + 数组形状解析）不回归；既有解析用例全数保持。
- 风险与取舍：
  - GitHub API 匿名限流（60/时/IP）：家庭出口 IP 低频手动检查可接受；共享出口 IP（代理）偶发 403 → 失败重试态兜底；
  - `/releases/latest` 自动排除 draft/prerelease，语义优于列表接口取首条；
  - TLS：GitHub API 要求 TLS 1.2+，API 23 默认启用，兼容验收机。

实施后回填实际改动清单：

- `app/src/main/res/values/strings.xml`（update_endpoint_url 填入真实 GitHub Releases latest 地址）
- `app/src/main/java/com/sofatype/ime/update/UpdateReleaseParser.kt`（parseDocument 顶层兼容单对象形状，数组路径不动）
- `app/src/test/java/com/sofatype/ime/update/UpdateReleaseParserTest.kt`（新增 latest 单对象解析与不可用态 2 个用例）
- `tools/mock/github-releases/README.md`、`DEVELOP.md`（mock 仅 debug 注入、默认真实源口径说明）
- `docs/issues/NEXT-ID.md`（取号回写 T102 / 下一编号 T103）、本文建档

## 验收

- 单测：解析器新增单对象（latest 形状）用例通过；既有数组 / mock 形状用例不回归；`:pinyin` 与 app 单测全绿。
- 模拟器端到端（仓库 Public 前置满足后）：debug 包不注入 mock、直连真实 endpoint 点「检查更新」，logcat endpoint = GitHub latest 地址，结果 = UpToDate（当前 0.2.1 == 最新 release）——证明「从 release 获取最新版」真实可达。
- 户主结论：待验收。
