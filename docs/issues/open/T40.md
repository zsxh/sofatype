# T40 · 键盘弹出初始焦点改字母 a

| 项 | 内容 |
| --- | --- |
| 编号 / 状态 | T40 / open |
| 类型 | bugfix |
| 对应 PRD | FR-A11（焦点导航）；户主拍板 2026-11-08（T12 终验附带） |
| 创建 / 关闭 | 2026-11-08 / — |

## 目标

键盘每次弹出（含收起后唤起重弹）的初始焦点落在字母区 [a] 键（现初始焦点为数字列 [1]，digit_1），便于直接开始打字。

## 改动

`FocusNavigator` 初始键口径与 `SofatypeImeService` 弹出时初始焦点设置由 digit_1 改为字母 a；同步核对依赖「初始键」的既有路径：候选行焦点回归丢失回退、引导卡主按钮回退丢失回退（两处「丢失回初始键」逻辑），相关单测同步更新。

## 原因

户主 T12 终验拍板（2026-11-08）：键盘弹出焦点应在字母 a——当前初始焦点在数字列 1，距字母区远、观感不佳。

## 验收

- [ ] 两处「丢失回初始键」回归路径行为一致，单测同步更新全绿
