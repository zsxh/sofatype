## 原因

2026-11-12 真机批次 review-qa 发现（MiTV4 API 23 实测，视觉截图 + uiautomator dump text 双证；详录设备档案坑 22）：组合态建立正常（composer 装载 total=24、候选 chips 可见），但组合串与选词均不落框，输入框恒占位文案；期间键面直出同样不落框——用户经由键盘的输入全部丢失（P1）。tap 输入框重建会话后恢复（恢复后此前失败组合串延迟落框出现「nn」双写，随修复一并核查）。复现链：default 夺回搜狗（坑 5 同族，无 Force stopping 指纹）→ `ime set` 切回 sofatype（服务重启、新 pid）→ 弹键盘输入。户主拍板（2026-11-12）：新立 bugfix 修复；与 T54 缺陷①「键盘自发重显劫持遥控键」分立（后者同日拍板暂不修复、挂账 open/T54）。
