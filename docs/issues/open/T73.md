## 目标

模拟器（API 34）补验 2026-11-15 真机批次如实标注的三项遗留，补齐 T71 / T72 验收闭环：

1. **T72 过期换号**：deviceKey 超 TTL（15 分钟）重连换新号——过期条目失号、新号按全表 max+1（表空回 01）口径核对。
2. **T72 LRU 满 8 台淘汰**：容量 8 满后最久未见淘汰、钉住键不淘汰、淘汰后容量守恒、表空回 01 复核。
3. **T71 release 门控运行期验证**：`ImeKeyTrace`「debug 构建 或 开关开启」在 release 构建随开关生效（关→零键控行、开→有键控行）。

## 改动

纯验证批次，预期零生产代码改动。验证通道开工时拍板：

- 过期换号：TASKS 允许验证期缩短 TTL——以测试期常量或注入时钟方式实现，不改生产默认值。
- release 门控：release unsigned 不可装机；候选通道 = release 包以 debug keystore 签名后模拟器装机（不改工程 signingConfig），或户主指定通道。
