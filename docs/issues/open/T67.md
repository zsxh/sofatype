## 目标

三条遥控交互修订（2026-11-14 户主真机使用反馈拍板；三条合并一个 issue 立项，**户主指示暂不实现**，实现另等指令）：

1. **候选翻页焦点落点分向**（中文输入候选行，T66 · 决策 53 单行翻页模型）：焦点在行尾候选按[右]翻下一页，焦点落**当页（新页）首候选**——现行口径不变；焦点在行首候选按[左]回上一页，焦点落**当页（回翻页）尾候选**——修订决策 53「翻页后一律落页首」条款（同原 T11 展开行「回翻落页末」口径，该口径曾随决策 53 废止、本条恢复）。
2. **键盘最右列按[右]直达「远程输入」**：字母 / 符号两键盘最右列（第 12 列）**全部按键**（[下屏] / [删除] / [完成]，两键盘该列键位同构）按[右]，焦点跳转副卡引导卡「远程输入」主按钮。现行仅行 3/4 纵向带按键可达（实际只有跨行 [完成] 键），行 1/2 最右键（[下屏] / [删除]）按[右]表缘不动，随本条修订。副卡为配对卡 / 已连接卡（无该按钮）或远程模式主卡时维持表缘不动；从按钮按[左]回进入前键位（T17 既有口径）不变。
3. **设置页返回键二次退出**：设置页按系统返回键**第一击不退出**，只在屏幕下方弹文字提示**「再按一次返回退出sofatype设置页」**；**2 秒内**再按返回键直接退出设置页，**超窗重新计**（首击只提示不退出）。提示形式 = **系统 Toast**（2026-11-14 会话内确认；底部居中短暂浮现，不新增页面元素、不改设计稿定稿）。边界不变项：键盘显示态 BACK 先收起键盘（FR-A1）、测试打字页 BACK 返回设置页（T63）语义不变。
