## 目标

远程模式会话全程，「退出远程」按钮焦点保持可触发：手机推送内容上屏后按钮不再丢焦点，直接 OK 一击完整退出远程（FR-B7 链路）；不再依赖「BACK 保活收起 → OK 唤起重入」绕行恢复焦点。具体修复口径（焦点保持 vs 装载后焦点回归）开工时拍板。

## 改动

计划改动（未开工，实现时按实际更新本节）：

- 预期落点 `SofatypeImeService.kt` 远程大字区装载路径（`renderRemoteText` → `fullScroll(FOCUS_DOWN)`，T15 既有代码）的焦点处理；渲染层改动控制在该链路，不触碰 BACK 分流（T74 `RemoteBackPolicy`）与服务链路。
- 单测：焦点回归策略若抽纯模型则补测；既有远程族单测随 `--rerun-tasks` 全量实跑回归。

## 原因

2026-11-15 T74 dev-review 走查发现（dev 坑 2，review-qa 独立复现）：进入远程后手机首次推送内容即丢焦点（装载滚动 `fullScroll(FOCUS_DOWN)` 夺走按钮焦点，归因对比 qa-focus-1/2），其后 OK 到达 IME 时 `performClick` 无目标（trace `focus=null`）不触发退出——「上屏后直接 OK 退出远程」路径失效；BACK 保活收起 → OK 唤起重入后焦点恢复（T17 路径聚焦退出按钮）。T15 既有代码，非 T74 引入（T74 渲染层零改动）。2026-11-15 户主拍板立项，开工另等户主指令。
