## 目标

逐音节「全拼 / 缩写」混合匹配：任意音节位置可为全拼前缀或首字母缩写——覆盖 zguo → 中国（首音节缩写 + 末音节全拼）、srf → 输入法（纯简拼）、zhly 声母简拼形态。一期两路口径（纯简拼 zg / 全拼前缀 zhongg）不回归；上层（Composer / Service / 候选栏）零改动。

## 改动

### 计划（开工前预注）

- `PinyinSegmenter` / `PinyinEngine` 引入逐音节双状态匹配（每音节位 = 全拼前缀状态 × 首字母状态）的动态规划匹配，候选评分区分「全拼位 / 缩写位」加权。

### 实际（2026-11-18 深夜 dev Round 1 实现）

- `pinyin/src/main/kotlin/com/sofatype/pinyin/PinyinEngine.kt`（唯一生产代码改动文件）：
  - 新增混合缩写路 `rankedMixed`：候选集沿用首字母倒排桶扫描（任何合法分段首段首字母必同首音节首字母，与简拼路同桶），逐词条跑新增 `mixedSegmentMatch` 逐音节可达 DP——每音节位四类消费：整音节（全拼位）、zh/ch/sh 整声母缩写（2 字母，翘舌判定 `isRetroflexInitial`）、首字母缩写（1 字母）、音节真前缀恰好吃满输入（组合态增量，只允许末段）；状态数上界 = 输入长 × 音节数，无切分组合爆炸；
  - `query` 合并改三层级：单字母仍取简拼路（一期口径不动）；≥2 字母 = 全拼命中排前 → 简拼命中剔重排后 → 混合缩写命中再剔重殿后（词 id 去重，同词保留首现层位），一期两路排序原样保留；
  - SPD1 格式、词库产物、`PinyinSegmenter`、上层（ChineseComposer / SofatypeImeService / CandidatePager / PinyinEngineLoader）零改动（git 管辖改动面 = pinyin 模块四文件：生产代码 1 + 测试 3，其中测试新增 1）。
- 测试（`pinyin/src/test/`）：
  - 新增 `MixedAbbrQueryTest.kt`（10 例）：缩写位+全拼位（zguo / zgu 增量）、声母缩写+全拼位（zhli / zhl / zhil）、纯声母两字母（zh / ch）、三段混合（srfa = 缩+缩+全拼）、一期纯简拼与全拼前缀不回归、跨路同词去重、i/u/v 恒空、limit 截断、非法输入；
  - `RealDictTest.kt` 新增真词库断言 5 例：zguo→中国居首（zgu 增量同命中）、srf→输入法居首、zhly→综合利用居首（一期简拼不回归）且张靓颖入列（zhang 整声母形态新词）、zhli→这里居首且治理入列、混合输入（zguo/zgu/zhly/zhli/srfa）无重复词；性能样例补 zguo/zhly/zhli/srf/srfa；
  - `AbbrQueryTest.kt` 两例按二期口径更新：「zh」由一期恒空断言改为声母形态命中（[中国, 重]）并补恒空例「zr」；「sh / shan / sha」补三层级与真前缀增量断言（shan 为 shang 真前缀、sha 为 s+ha 前缀等全拼路首音节桶盲区形态，混合路殿后）。
