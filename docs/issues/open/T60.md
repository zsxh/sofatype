## 目标

APK 安装到真机后，电视桌面（launcher）出现 sofatype 应用入口，遥控器选中直达设置页；不再依赖 adb `am start` 与系统输入法设置深层路径。

## 改动

Round 1 实际改动（2026-11-11，dev）：

- 清单（`app/src/main/AndroidManifest.xml`）：`<application>` 补 `android:icon="@mipmap/ic_launcher"` 与 `android:banner="@drawable/banner_sofatype"`；`SettingsActivity` 补一个入口 intent-filter，`MAIN` + `LEANBACK_LAUNCHER` + `LAUNCHER` 三个声明同列一个 filter（TV 桌面与通用应用列表均解析该 Activity）。IME service、method.xml、设置页逻辑零改动。
- 新增图标资源：`mipmap-{mdpi,hdpi,xhdpi,xxhdpi,xxxhdpi}/ic_launcher.png`（48/72/96/144/192 px）、`drawable-xhdpi/banner_sofatype.png`（320×180 px）。色值取 PRD 6.1 Token（accent / on-accent / bg / text-primary）；图形沿用设置页品牌块语言（accent 圆角方块 + on-accent「S」，banner 另加「sofatype」字标）。图标图形方案为占位实现，2026-11-11 户主拍板接受定稿（后续如需专用设计另立任务）。
- 模拟器实测（API 34 `emulator-5554`，AVD sofatype-tv，`-no-snapshot` 冷启）：`cmd package query-activities` 对 MAIN+LEANBACK_LAUNCHER 与 MAIN+LAUNCHER 均解析到 `com.sofatype.ime/.SettingsActivity`；桌面 Apps 页签 Installed Apps 行出现 sofatype 入口（banner 呈现，焦点标题「sofatype 输入法设置」）；键码导航 HOME → 右×2 → 下×2 → 右×5 → OK 后 `topResumedActivity` 为 `.SettingsActivity`，设置页正常呈现。取证 `screenshots/T60/dev-r1-home.png`、`dev-r1-launcher-apps.png`、`dev-r1-launcher-focus.png`、`dev-r1-settings-entry.png`。
- 回归实测：① `adb shell am start -n com.sofatype.ime/.SettingsActivity` 直达（resumed t227，`dev-r1-am-start.png`）；② 系统输入法设置（`android.settings.INPUT_METHOD_SETTINGS`）列出「sofatype 输入法 Settings」入口，键码 OK 直达 `.SettingsActivity`（resumed t228，`dev-r1-ime-settings-row.png`、`dev-r1-ime-settings-entry.png`）；③ `ime set` 双向切换成功，OK 探针 ImeKeyTrace `onWindowShown` 键盘唤醒正常（`dev-r1-ime-switch.png`）。②的直达验证与①③中键码直达在默认输入法临时切 Gboard 时完成（原因见「踩过的坑」）。

## 原因

2026-11-11 户主真机使用反馈：APK 装到小米电视4后，系统输入法里能切到 sofatype，但电视桌面没有应用图标，进不去设置页；当前进设置页只有 adb `am start`（开发通道）与系统输入法设置两条路径。

## 踩过的坑

- 模拟器键码被本 IME 消费（2026-11-11 Round 1 实测，AVD userdata 保留）：sofatype 为默认输入法时，注入的 DPAD_CENTER 走键码通道先进本 IME——T59 隐藏态「确认键唤起键盘」语义将其消费为唤醒键盘（ImeKeyTrace `onKeyDown keyCode=23` 佐证），桌面与系统设置列表的行点击不发生；`dumpsys input_method` 可见 mCurClient 挂在 launcher / tv.settings 的编辑器上、`mInputShown=true` 而键盘不可见（与 T59「mInputShown 不可靠」一致）。BACK 键码可收起键盘；把默认输入法临时切 Gboard 后各入口路径全部可达。本 issue 清单只加入口声明与图标资源、未改 IME 键码逻辑，该交互与本次改动无关；真机（MiTV4 tvhome）常态（默认输入法即 sofatype）是否复现，待真机复验轮核验。
