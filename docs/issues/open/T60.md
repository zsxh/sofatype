## 目标

APK 安装到真机后，电视桌面（launcher）出现 sofatype 应用入口，遥控器选中直达设置页；不再依赖 adb `am start` 与系统输入法设置深层路径。

## 改动

未开工。创建时定性（代码核对，2026-11-11）：`app/src/main/AndroidManifest.xml` 中 `SettingsActivity` 仅声明 `exported=true`，无 MAIN + LAUNCHER / LEANBACK_LAUNCHER 入口 intent-filter——应用不出现在电视桌面与应用列表，与户主反馈现象吻合。预计改动集中在清单声明：给 `SettingsActivity` 补 TV 桌面入口 intent-filter；是否同时保留 LAUNCHER、是否需补 banner / 应用图标资源，实现时按 MiTV4 桌面实测回填本节。不动 IME service、method.xml 与设置页逻辑。

## 原因

2026-11-11 户主真机使用反馈：APK 装到小米电视4后，系统输入法里能切到 sofatype，但电视桌面没有应用图标，进不去设置页；当前进设置页只有 adb `am start`（开发通道）与系统输入法设置两条路径。
