## 踩过的坑

1. **模拟器窗口帧滞留旧键面（「步进后全/半切换」场景，未定性根因，模拟器已确认非应用逻辑缺陷）**：行步进窗口发生过之后，在下移态按[全/半]切换——逻辑层全部正确（诊断 trace 证实 rebuildKeys 执行、行容器子视图与焦点导航 keyViews 均为新键位、输出值正确（全角《/半角 , 各按当前页输出）、焦点探针 `onKeyDown focus=fw_r2c1` 响应新键位），但窗口帧滞留旧键面（焦点框位置跟随新视图、键面字符停留在旧页），`root.invalidate()` 强制失效也不恢复；后续焦点移动产生的新帧同样滞留旧字符。offset=0（未步进）时全/半切换渲染正常；进符号键盘/窗口步进本身的 rebuild 渲染正常。已确认 4+ 次复现（同一路径）、跨 3 个模拟器实例。判定：应用层视图树操作正确，疑似 API 34 模拟器渲染管线（gfxstream）缺陷；真机待复验定性。证据：screenshots/T64/t64-b1-full-bottom-after-focus.png（滞留态：焦点框在 fw_r2c7、键面半角）+ t64-imekeytrace.log。
2. **边界箭头视图必须入 overlayViews 注册表**：首版箭头视图只 addView 未注册进 overlayViews，布局/窗口切换重建时旧箭头残留（下移态双箭头并存）。修复：箭头与浮层键同入 overlayViews，bindOverlayKeys 开头统一移除（证据：修复前截图曾见下移态双箭头，修复后 t64-a2 只上箭头）。
3. **卸载重装后 IME 不被 ime set 识别（enabled_input_methods 被清）**：`adb uninstall` + 重装后包被系统识别但 `ime list -s` 不显示、`ime set` 报 unrecognized——卸载把 secure 表 `enabled_input_methods` 里的本 IME 条目清掉了（`ime list -s -a` 可见、`settings get secure enabled_input_methods` 缺本 IME）。恢复：`pm enable com.sofatype.ime` + `settings put secure enabled_input_methods` 追加回本 IME 条目（注意 shell 引号：值含分号须整体引号包裹，adb shell 直接拼会被 sh 拆成多条命令）。
4. **模拟器后台作业超时会回收模拟器进程**：`nix run .#tv-emulator` 放 run_in_background 且带 timeoutMs（如 60s）时，超时到期模拟器进程被回收（本轮 23:49 实测进程消失、正常保存快照退出）。重启后默认快照已删无碍；冷启命令应不设 timeoutMs 或显式设足够长。
