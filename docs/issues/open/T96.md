## 背景

2026-11-22 户主会话拍板（接 T94/T95 同日评审收尾后）。T94 词包插件机制（设置页挑选 + GitHub Release 下载）与 T95 流水线自动化已完成本地闭环并通过评审，户主拍板 DROP 该路线：热词库体量仅几百 KB，无需运行时下载与用户挑选，直接构建期内置 APK 离线使用——实现更简单、零外部词库地址依赖、用户无感知。词源只需两路：搜狗「网络流行新词」周更热词库与百度热搜词；不含搜狗「天文词汇大全」等静态专业词。同日追加拍板：app 未来更新节奏为**年更**，热词目标是**历年累积热词库**（跨年历史热词），不是当期热词快照。

## 需求与口径

1. 方案替代（推翻性，新压旧）：废止 T94 词包插件机制与 T95 GitHub 发布链路——设置页词库子页、词包勾选下载、manifest 分发 URL、GitHub Actions / Release 均不再使用。基线口径回退：`docs/PRD_20261104.md` 1.4 的词包联网条款（T94 口径 10 修订）随之失效，恢复「输入处理全本地 / 局域网」，热词为 APK 内置数据资源。
2. 内置热词多源，目标为**历年累积**（2026-11-22 拍板：app 年更，收跨年历史热词、非当期快照）：
   - 搜狗路：「网络流行新词」累积库本体（scel 自带拼音，官方周更、现第 6626 版 / 9,097 条，多年累积库；实施前核实旧词是否裁剪）；
   - 百度路：历年热词——官方「百度沸点」年度榜单（2008 年起逐年发布，每年 13~26 子榜，无 API，逐年收集）+ 实时榜多日积累；
   - 长尾资源路（2026-11-22 追加拍板：网络公开的长尾热词资源一并整合）：第三方热搜按日归档、权威年度榜单、开放中文词库数据集等，逐源评估后纳入，候选清单见「方案评估」预研；二手镜像数据只作构建期原料，逐源留证；
   - 不含搜狗「天文词汇大全」。注音与去重口径不变（非拼音词条注音补齐、查主词库去重）。
3. 用户无感知：不新增设置页词库挑选 UI，热词无开关、无下载、无进度；引擎自动并入热词候选。
4. 更新方式：热词随 app 更新发布，节奏对齐**年更**——每年发版前刷新重建一次历年热词库（搜狗累积库整包重抓 + 百度历年榜增量并入）；不依赖任何外部词库地址；构建期与运行时均零外部词库网络依赖。
5. 词源入库与构建零网络（沿决策 28 / 29 口径）：热词源文件入库 + sha256 门禁；gradle 构建期不抓网；发版流程新增「刷新热词源」人工步骤（抓取 → 转换 → 核对 → 入库）。
6. 引擎并入：热词与主词库构建期合并（合并进单一 SPD1 或随包第二数据，形态实施时评估，沿 SPD1 / DictFormat）；热词频次加权沿 T94 实测口径评估，保证热词可进候选前列且常用词序不受损；候选装载仍仅由中文组合态触发（决策 42 不变）。
7. T94 已落地机制代码处置：设置页词库子页、词包下载链路、`DictPackManifestParser` 等在实施中移除或退化，倾向移除死代码；实际清单实施后回填「方案评估」。
8. 隐私红线不变：热词是应用分发的内置数据，非用户输入；运行时无任何词库网络请求。

## 方案评估

实施前预评：

- 可复用 T95 资产：ScelDictParser（ECS / DCS 头解析）、热搜自动筛词（screen_hot_words.py）、pypinyin 注音、SPD1 转换与确定性口径、sha256 门禁模式——从「流水线产物」转为「构建期入库原料」。
- 影响模块：`:pinyin`（词源与构建任务扩展）、`:app`（移除词包下载与设置页链路、引擎装载点改内置 assets）、`tools/wordpack/`（抓取与转换脚本转本机词源刷新工具）、`flake.nix`（工具链已有 python3 + pypinyin，沿用）。
- 回归面：主词库 ConvertDict / VerifyDict / sha256 门禁零改动；候选刷新预算（第 8 章 ≤200 ms）并入热词后复测；无热词场景行为一致性；设置页焦点导航（移除词库子页后不回归）。
- 百度历年词源预研（2026-11-22，选型待户主拍板）：官方「百度沸点」2008 年起逐年发布（2023 年度榜 2023-12-25 发布、5 系列 13 榜；2023 年度榜单亦于 2024-01 沸点盛典披露），每年约百余词、无官方 API，逐年收集依赖百科 / 新闻页人工整理，词权威但工程量中等；第三方按日归档仓库（`hot_searches_for_apps` 2023-08 起 32 平台、`EverydayNews` 约 2.5 年 / 950+ 天 / 70 万条）细粒度覆盖近两年余（2026-11-22 户主拍板：长尾热词网络资源一并整合，第三方归档转为采用）。体量评估：历年累积总词量可能达数千至数万条，注意 SPD1 单包词条上限（T95 实测约 1.1 万条即跳过 306），合并形态实施时评估（多内置包或上限调整）。
- 长尾热词资源候选清单预研（2026-11-22，逐源核实与取舍在实施时定）：①第三方热搜归档——`hot_searches_for_apps`（2023-08 起 32 平台按天 Markdown）、`EverydayNews`（约 2.5 年 / 950+ 天 / 70 万条 CSV：百度 / 微博 / B 站）；②权威年度榜单——咬文嚼字「年度十大流行语」（2008 年起每年 10 词，2025 版已发布）、国家语言资源监测与研究中心「年度十大网络用语 / 流行语 / 新词语」（汉语盘点系列）；③开放词库数据集——清华 THUOCL（主流网站社会标签 / 搜索热词整理，含 DF 词频、多轮人工筛选）、Cheer 中文网络流行语数据集（ACL 2025，1,127 词条带释义，输入法只取词表）。逐源核实项：许可 / 版权、词条正确性抽样、格式可解析性、维护持续性；来源可疑或不带许可的弃用。
- 风险与取舍：APK 体量增大几百 KB 量级（可接受）；热词新鲜度随 app 更新节奏衰减、无运行时更新（户主已接受）；scel 版权口径沿 T95 拍板（官方条款限个人使用，私人家用，产物随 app 不对外分发词包文件本身）。

## 验收

口径清单（执行后补结果，区分模拟器已验证 / 真机已验证）：

- APK 内置热词生效：打样例热词出候选，样例须含**历年词**（早年流行语与近期热词各若干）；设置页无词库挑选入口。
- 零外部依赖：运行时与构建期均无词库网络请求；T94 机制代码处置完成并有留证。
- 主链路回归：候选刷新预算 ≤200 ms 复测；既有输入行为一致性核对。
- 单测强制实跑（`--rerun-tasks`）：热词源解析、合并去重、加权排序、确定性（同源重跑 sha256 一致）。
- 词源门禁：热词源文件 + sha256 入库；构建零网络复测；长尾资源逐源评估结论（许可 / 正确性 / 格式）留证。
- 真机验证：模拟器通过后另提请户主安排。
