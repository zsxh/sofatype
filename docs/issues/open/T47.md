## 目标

基线设备（小米电视4，Android 6.0.1 / API 23）「检查更新 → 下载 → 安装」链路改走 UI 渠道：应用转交系统安装器完成安装，用户在系统安装器界面确认；安装结果可判定、可观测。原 PackageInstaller 会话直装口径在本机废止，保留为 API 24+ 分支。

## 改动

实际改动（2026-11-09 Round 1 落地）：

1. 安装提交：新增 `update/InstallChannel.kt` 渠道门控纯模型（SESSION_MIN_SDK=24）。API 24+ 既有 PackageInstaller 会话分支保留、逻辑逐行未动；API≤23 走 UI 渠道 = `file://` + ACTION_INSTALL_PACKAGE（NEW_TASK），ActivityNotFoundException 兜底回失败态。无新依赖，FileProvider 未引入（会话分支走流式写入无需 URI；targetSdk 34 的 FileUriExposed 检查只在 API 24+ 设备触发，基线设备不适用）。
2. 结果判定：新增 `update/UiInstallOutcome.kt`——`UiInstallReceipt.decisionFor`（严格升 = UPDATED；相等 / 降级 / 非法 before = NOT_UPDATED）+ `UiInstallMarker` 编解码（载荷 `before=<code>`，非法与非正值拒读）。SettingsActivity 接线：UI 渠道提交前先落盘标记，onResume 重进前台判定（升级成功 = 绿点「更新安装成功」；未升 = 失败红点 + reason_ui_install_not_updated + 重试）；判定即清标记并删 cache 文件。`UpdateFailureReason` 增 UI_INSTALL_NOT_UPDATED；`strings.xml` 增 2 条（status_install_success / reason_ui_install_not_updated），零删改既有条目。
3. mock 验收件：`sofatype-0.2.0.apk` 重制为 0.2.0(2)；产制 = init 脚本注入（`tools/mock/github-releases/build-incremented-apk.gradle` 入库，README 命令同步；`-Pandroid.injected.*` 方式 AGP 8.2.2 实测无效已废止）；工程默认 versionCode 保持 0.1.0(1)（决策 19）。
4. 新增单测 12 例：InstallChannelTest 4 例 + UiInstallOutcomeTest 8 例。
5. PRD 同步：FR-D4 与决策 36 已修订在案，实现以 PRD 为准；docs 归 lead 维护。

## 原因

2026-11-09 户主拍板（决策 36）。会话通道在本机两个缺口：①授权判定读 `global install_non_market_apps` 位，UI 开关写 secure 位，未授权时提交即 `INSTALL_FAILED_USER_RESTRICTED`，无任何系统界面（坑 15）；②授权后提交静默无弹窗，结果不可观测；且 T27 Round 2 的「静默直装成功」实为同版本复装（mock 包版本未递增），真升级从未被验证。UI 渠道（系统安装器）承载全部用户确认与安全检测界面，在这台设备上被外部应用反复走通。
