## 目标

字母键盘两条模式切换链路实现组合态干净切换：

1. 中文输入态（含拼音组合 / 候选词）按[大写]（上档）键 → 必须切换成英文输入状态；已有候选词取消，候选词不得上屏进输入框；
2. 英文大写态按[中/英]键 → 必须切换成中文输入状态，且为零候选词状态（不残留组合与候选）。

## 改动

Round 1（2026-11-11，dev）：

- `app/src/main/java/com/sofatype/ime/SofatypeImeService.kt`：
  - `KeyAction.ToggleCase` 分支：新增中文态判定——中文态按[大写]取消组合态（组合串与候选作废、不落输入框）、语言模式切英文、候选栏刷新清空；大小写状态仍随该键翻转（默认小写态落大写英文）。英文态维持 FR-A3 纯大小写切换，行为不变。
