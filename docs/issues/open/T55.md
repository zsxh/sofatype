## 目标

字母键盘两条模式切换链路实现组合态干净切换：

1. 中文输入态（含拼音组合 / 候选词）按[大写]（上档）键 → 必须切换成英文输入状态；已有候选词取消，候选词不得上屏进输入框；
2. 英文大写态按[中/英]键 → 必须切换成中文输入状态，且为零候选词状态（不残留组合与候选）。

## 改动

未开工。预计改动集中在 `SofatypeImeService.onKeyDown` 模式键分支（上档 / 中英切换）与组合态复位链路（composer 清空、候选栏清空、焦点回归键区）——实现前先核实现状代码，按实际实现回填本节。

## 原因

2026-11-11 户主真机使用反馈：中文态按[大写]后未转英文态、候选词残留并被输入进输入框；英文大写态按[中/英]后未落中文零候选态。户主拍板口径：模式切换键必须同时复位组合与候选。
