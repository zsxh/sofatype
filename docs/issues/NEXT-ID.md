## 取号规则

1. 新建 issue 前先读本文件，取「下一个可用编号」作为新 issue 编号（全局变更编号，T 前缀连续递增、closed 不复用）。
2. 取号同时回写本文件：「下一个可用编号」+1、「最后已用编号」改为取走的编号、更新「最近更新」。**先写回、再开始填充 issue 正文**，避免并发撞号。
3. 若本记录与目录实况冲突（如 `open/`、`closed/` 中已存在更大编号），以目录实况为准，先修正本记录再取号。
4. 纯文档调整不建 issue，不取号（README 规则 1）。
