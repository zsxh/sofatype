## 目标

测试打字页（TestTypingActivity，debug 门控）提供两个输入框，支撑 T74 真机复验的「真实双输入框表单切换取证」：键盘收起保活后焦点切到另一个输入框，唤起键盘自动回远程模式已连接、缓冲保持，上屏落当前焦点输入框。

既有单输入框语义不回归：三件套（测试输入框 / 填入示例文本 / 全选）行为不变；release 页面仍无输入框（GONE）。
