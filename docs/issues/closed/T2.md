## 目标

一个最小设置页壳子，含稳定可控的测试输入区（仅 debug 构建显示）。测试输入区是键盘与上屏验收的唯一输入宿主。

## 改动
新增设置 Activity 与配套资源；色值/规格全部 Token 化（PRD 第 6 章）：

- `app/build.gradle.kts`：开启 `buildFeatures.buildConfig`（`BuildConfig.DEBUG` 门控需生成 BuildConfig 类）。
- `app/src/main/AndroidManifest.xml`：注册 `SettingsActivity`（`exported=true`，供 adb `am start` 验收直达）；application 挂深色主题。
- `SettingsActivity.kt`：debug 构建显示测试输入区并绑定「填入示例文本」（填入后光标移末尾）与「全选」（`selectAll()`）；release 构建置 `GONE`（决策 21 门控）。
- `res/layout/activity_settings.xml`：面包屑「sofatype 输入法 ｜ 设置」+ debug 测试输入区（输入框 + 两个辅助按钮）。
- `res/values/colors.xml`：PRD 6.1 色彩 Token 全集（rgba→ARGB 换算注释）；`dimens.xml`：规格 Token（1080p 基准 px ÷ 2 = dp/sp，按 tv_1080p 密度 320）；`strings.xml`：文案与无障碍标注（交互元素均带 text/hint/contentDescription）；`styles.xml`：`Theme.Sofatype`（framework Material 主题，无第三方依赖）。
- `res/drawable/`：`bg_test_input`、`bg_btn_accent` 状态选择器（焦点态 = 提亮 + 主色描边，PRD 6.4）。
- `res/xml/method.xml`：IME 声明设置入口（FR-D1）——`android:settingsActivity="com.sofatype.ime.SettingsActivity"`。按 lead 拍板（2026-11-05，方案 A），T2 只创建本文件、不建 IME service、不加 meta-data；文件暂为就位状态，T3 声明 InputMethodService 时以 `<meta-data android:name="android.view.im" android:resource="@xml/method">` 引用后，系统输入法设置的入口即生效。
- 范围边界：品牌区、版本信息卡、底部操作提示属 T20；占位键盘属 T3，均未实现。

## 原因
键盘与上屏验收需要稳定可控的输入框宿主（决策 21：不单建测试 app）；release 构建不得含设计稿之外的测试区。
