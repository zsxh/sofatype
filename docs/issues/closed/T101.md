## 背景

2026-11-24 户主会话拍板（GitHub 公开与 license 调研触发）。仓库推公开后即构成对入库数据的公开再分发：搜狗 scel 官方条款「限个人使用」（T95 拍板口径为私人家用）与公开仓库直接冲突；百度沸点 / 实时榜为无单独许可的灰色词源。户主指令：删掉搜狗和百度源，换开源源。选型对照 Rime 生态做法（官方词库只用开放来源并逐源登记许可；商用词库数据一律不随发行物分发），选定 THUOCL（清华大学开放中文词库，MIT，Copyright 2018 THUNLP，许可原件已核验）作为替换源。

## 需求与口径

1. **删除三个热词源**：`sogou-liuxingxinci.scel`、`baidu-boiling-years.txt`、`baidu-realtime-days.txt` 出库（`baidu-realtime` 沿 T99 已停并，出库后复评留证由 git 历史承担）；`sources.sha256` 同步更新。
2. **引入 THUOCL 开源源**：派生文件 `thuocl-open.txt` 入库（hot 注音行格式：`词 频次 0 拼音…`）。派生口径：上游 11 域词表（IT / 财经 / 成语 / 地名 / 历史名人 / 医学 / 饮食 / 法律 / 汽车 / 动物，共 10 域参与 + 排除诗词句类）合并跨域去重（同词取最大 DF）→ 按 DF 降序取前 **12000** 条 → 过滤纯汉字 1~6 字 → pypinyin 注音（不可注音跳过）。上游原件不入库（体量数 MB；构建零网络不受影响——派生文件即构建输入，sha256 锁定）。
3. **保留两源**：`nlc-netlang-years.txt`（语监中心年度网络用语）、`yaowenjiaozi-years.txt`（咬文嚼字年度流行语）——事实性榜单词表，NOTICE 如实登记。
4. **构建与工具适配**：
   - `pinyin/build.gradle.kts` 的 `hotDictSources` 表换为 `thuocl-open` / `nlc-netlang` / `yaowenjiaozi` 三源（scel 原料格式与 `ScelDictParser` 保留：通用解析能力，测试继续覆盖）；
   - 新增 `tools/wordpack/fetch_thuocl.py`（上游下载）与 `build_thuocl_source.py`（派生 + 注音，确定性）；`refresh_hotwords.sh` 改写为 THUOCL 重取 + 派生 + 锁重算链；
   - 移除搜狗 / 百度抓取链脚本（`fetch_sogou_scel.py`、`fetch_hot_search.py`、`screen_hot_words.py`、`refresh_realtime.py`、`hot_search_annotate.py`），git 历史留证；
   - `HotDictSourceLockTest` 断言随源清单更新。
5. **文档同步**：`docs/DICTS.md`（源表 + 移除记录）、`NOTICE`（补热词源登记欠账 + THUOCL MIT 与学术引用格式）、`DEVELOP.md`、`tools/wordpack/README.md`、`docs/HANDOFF.md`（当前快照词库条 + 决策速查 T101 行）、`CHANGELOG.md`（未发布）。
6. 运行时零改动：`hotwords.bin` 消费链路（档位频次、主词库去重、DictHotMerge）不变；本次为数据源替换。

## 方案评估

预评（实施前）：

- 影响范围：`pinyin/dictsrc/hotwords/`（源文件与锁）、`pinyin/build.gradle.kts`、`pinyin/src/test`（锁定断言）、`tools/wordpack/`、五份文档；运行时代码零改动。
- 回归面：主词库链路零触碰；`buildHotDict` 的档位频次 / 去重 / 确定性产物语义不变；`-PsofatypeHotDicts=` 空值全关口径不变。
- 风险与取舍：
  - THUOCL 为 2016-2017 静态词库（DF 值来自当时语料），无「网络流行新词」时效语义——热词频道语义变为「开放领域词库补强」，词条新鲜度下降（接受，合规优先）；
  - 截断参数 N=12000 为拍板内定值（对齐原搜狗 11 480 词量级），可调；
  - THUOCL 词条与主词库重叠率未知，实际并入 bin 的净增词条数会低于 N（构建统计里如实报数）；
  - 搜狗 scel 解析器（`ScelDictParser`）保留为通用格式能力，非死代码判定：测试在、原料格式在册。
