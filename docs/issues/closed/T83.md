## 目标

中文组合态支持首字母简拼：输入首字母串（如 zg）即出简拼匹配候选（zg 实测「这个 / 中国」前 2）；单字母按键即刻出首字母匹配词（修复现状 21/26 个字母零反馈）；全拼查询行为不回归。交付 `:pinyin` 引擎层实现与单测，上层（Composer / Service / 候选栏）零改动。

## 改动

### 计划（创建时写明）

- `pinyin/src/main/kotlin/com/sofatype/pinyin/PinyinEngine.kt`：
  - init 派生词条首字母串（各音节首字母拼接，如 [zhong, guo] → zg）+ 按首字母建 26 路倒排桶；SPD1 格式与词库文件不变，运行时派生；
  - `query` 改双路：全拼前缀路（现行口径不动）+ 简拼前缀路；输入 ≥ 2 字母时合并 = 全拼命中排前、简拼命中按内建频次排后、词 id 去重；单字母取简拼路（实测为全拼路超集）按频次统一排序；
- `pinyin/src/test/kotlin/com/sofatype/pinyin/`：新增简拼单测——合成词库边界（双路命中去重与排序、单字母超集、i / u / v 无候选、limit 截断、非法输入空列表）+ 真词库口径断言（zg / bj / 单字母 top1、频次组内单调）+ 查询性能量级复跑；

## 原因

遥控逐键打字前几键零反馈：现状仅「全拼前缀」单路匹配，z / zh / zho / zg / nh 等输入全部空候选，须打到完整首音节（如 zhong，5 键）才出词；户主实际使用反馈「单字母经常没有字出来」。简拼为主流输入法标配（搜狗等）。词库复算佐证（65 105 条词条）：zg 命中 295 词、nh → 你好第 1、单字母 23/26 键出高频词，仅凭内建频次排序即可用（调研明细见 PRD_20261118 第 3 章与 TASKS T83 行）。
