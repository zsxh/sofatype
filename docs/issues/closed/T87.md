## 目标

词库（高频子集 / 全量）加载失败时，在**任何构建变体与日志开关状态下**logcat 都有一条恒记失败日志（含 scope 与失败段），保住 release 现场取证能力；门控 trace 明细行（决策 60 口径）不变。失败日志只记技术事实（scope / entryCount / 异常类名），零输入内容（隐私红线与 T71 守卫口径不变）。

## 改动

### 现状（T85 引入的缺口）

- T85 Round 1 将失败日志点由旧 `Timber.w`（恒写 logcat）迁入门控 `trace()`（门控 = debug 或开关）→ release 构建且日志开关关闭时 `pinyin engine load failed` 在 logcat 不可见（review-qa Round 1 评审发现，户主拍板补恒记日志）。

## 原因

T85 Round 1 评审发现 release 现场排查能力缺口：词库加载失败（如 assets 缺损、IO 异常）在 release + 开关关闭时完全静默，现场只剩「无候选」表象无法定位。户主拍板补恒记失败日志（T85 归档同日，编号顺延 T87）。
