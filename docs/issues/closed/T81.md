## 目标

符号键盘上 OK 按 [全/半] 键切换全角/半角后，遥控焦点保持在 [全/半] 键上（键面当前态指示「全/半」亮暗随切换实时翻转）；不再跳回键区左上角数字键 digit_1。连续切换与后续方向导航从 [全/半] 位直接起走。

## 改动（实际实现，dev Round 1 2026-11-17）

- `SofatypeImeService.kt` `execute` 的 `KeyAction.ToggleWidth` 分支（改动后 1691-1701 行）：`rebuildKeys(…, requestInitialFocus = true)` → `requestInitialFocus = false`，紧接补 `keyViews[SymbolsLayout.TOGGLE_WIDTH_ID]?.requestFocus(View.FOCUS_DOWN)`——与 [中/英] 键（`KeyAction.ToggleLanguage`）既有「焦点保持本键」接线同型；分支注释同步改写（删除「焦点回初始键（既有口径）」表述，标注 T81 户主拍板修订）：


## 原因

2026-11-17 户主真机使用反馈：符号键盘全角/半角切换后焦点挪到数字键盘（digit_1），预期留在 [全/半] 键。现状根因 = T8 建设期接线：`ToggleWidth` 分支 `rebuildKeys(…, requestInitialFocus = true)`，重建后焦点落 `SymbolsLayout.initialCell`（1,1）= digit_1（`SofatypeImeService.kt:1691-1699`）；T64 走查定性「既有口径」、T66 走查再次记录并建议「如需体验打磨另立任务评估」（HANDOFF 遗留观察挂账条目）。全/半连续切换是高频操作，焦点每次跳走需要重新走位，实机体验差；户主本次反馈即拍板预期语义 = 焦点留在 [全/半] 键（修订该既有口径）。
