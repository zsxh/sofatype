## 目标

键盘星夜青视觉基线：Token 化色值规格 + 主副卡静态布局。视觉与设计稿画板①一致。

## 改动

- 键位模型：新增 `KeyboardLayout.kt`（纯 Kotlin，无 Android 依赖）——画板① 4 行键位（数字列 / 字母区 / 功能键区）+ 跨两行完成键，含键面文字与图标、样式变体、动作语义与无障碍标注；删除 T3 的 `PlaceholderKeyboard.kt`。
- 键盘悬浮层：新增 `layout/ime_keyboard.xml`——覆盖区 322dp（644px）透明停靠屏幕底部；主卡 636×274dp（候选栏占位 26dp + 键盘区 600dp 宽 4 行）+ 右侧副卡占位 236×274dp，主 / 副卡各含底部柔影垫层。`SofatypeImeService` 改为模型驱动程序化生成键帽（文字键 TextView / 图标键 ImageView）；T5 仅「下屏」动作生效（`requestHideSelf`），其余动作语义留 T6/T7/T8/T10 接线；`onEvaluateFullscreenMode` 恒 false 保留（T3 基线）。
- Token 补全：`dimens.xml` 新增键盘节（覆盖区 / 卡片 / 键帽 / 间距 / 完成键 / 图标 / 柔影垫层尺寸，1080p 基准 px÷2 口径，逐项标注设计稿原值），删除占位 Token `ime_placeholder_height`、`ime_key_gap`；`colors.xml` 新增柔影色 `card_shadow`（PRD 6.3 黑 55% 模糊 30 的垫层近似）；`strings.xml` 删除 T3 占位键字符串。
- drawable：`bg_card`（card 底 + 描边 + 圆角 38px）、`bg_key`（key 底，按压提亮 key-hover）、`bg_key_done`（accent-wash 底 + 主色描边）、`bg_card_shadow`（柔影垫层，外扩 6dp + 40% 黑 + 圆角 48px 近似 blur 扩散观感）；键帽图标 5 枚（上档 / 下屏 / 删除 / 光标左右，vector 线条复刻画板① SVG）。
- `.com` 键功能键样式（评审第 1 轮 Major 1）：画板① 中 `.com` 为 `.bkey-fn`（首版误读为普通字符键），改为 FUNCTION 变体 + SMALL 字号 + 直出文本动作。
- 单测：新增 `KeyboardLayoutTest.kt`（12 例：行列结构 / 26 字母齐全有序 / 数字列 / 行 4 光标键 / 功能键齐全 / id 唯一 / 下屏动作 / 图标-动作映射 / 完成键变体与浮层位置 / 功能键字号 / `.com` 功能键样式锁定 / 图标键无障碍标注）；删除 `PlaceholderKeyboardTest.kt`。

## 原因

FR-A2 布局要求；色值与规格 Token 化是视觉规范硬性要求，先立 Token 避免硬编码散落。

## 踩过的坑

1. 柔影垫层首版 Token 换算错误：外扩后的垫层尺寸误按「px 口径再 ÷2」写入（等于卡片半宽半高），垫层被不透明卡体完全遮住、只剩副卡左侧局部晕露出的假象；且卡片行 `clipToPadding` 默认为 true，把溢出到水平 padding 区（72px）的柔影裁掉——表现为「左右外侧无晕、卡间有晕」。修正：垫层尺寸按 dp 口径 = 卡片 + 2×6dp 外扩；卡片行加 `clipToPadding=false`。
2. 垫层 Token 修了一半（评审第 2 轮 Major）：修主卡口径时副卡垫层仍复用主卡宽 Token（648dp），副卡仅 236dp 宽、居中后左右各溢出 412px（206dp），垫层左缘伸到主卡右半区（实测暗化左缘 x=964 与理论 1376−412 精确一致），主卡右半区键帽被 40% 黑罩暗（#1D242F→#11161C 系）。教训：复用 Token 前先核对几何前提（两卡宽度不同）；采样验收必须覆盖全部区域，不能只采外侧带（首版采样恰好落在污染区外，得出「观感无缺失」的错误结论）。修正：副卡垫层独立 Token `ime_side_card_shadow_width` 248dp（236dp + 2×6dp，与主卡同口径）。
3. IME 窗口边界吃掉柔影顶带（系统约束，非缺陷）：`dumpsys window` 实测 InputMethod 窗口 frame=[0,484][1920,1080]，窗口顶与卡顶重合（导航栏 48px 使 IME 可用区下移），柔影顶带（y 472~484）落在窗口外不可见；底带被导航栏遮挡。画板① 柔影主要观感区（左右 / 卡间）不受影响。
4. 走查沿用 DEV-GUIDE 1.5 既有口径：uiautomator dump 不含 IME 窗口，键位坐标按截图目测 + 布局推算（下屏键 tap 1268,626）。
