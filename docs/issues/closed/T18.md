`onRemoteCommit` 主线程同步等待回执写完成上限 2s → **已异步化**：主线程只执行 IME 写入，ack + 停服移交单线程 teardown 串行执行；主线程阻塞消除（W8 走查 committed → disconnect → CLOSE 1000 帧序实证、全程无 ANR / StrictMode / crash），时序依赖（回执先于停服、帧不交错）由单线程 teardown + 各连接单线程 ConnectionWriter 保持。同步等待写完成的语义仍存在于 teardown 线程（上限 2s），阻塞面已不在主线程。

## 踩过的坑

1. **teardown 线程直调 UI 回调 → CalledFromWrongThreadException → 进程崩溃**：stop 编排移入 teardown 线程后，`stopNow()` 里 `onPairingStateChanged?.invoke()` 未改派发——旧 stop 全在主线程直调故未暴露；BACK 退出远程实测崩溃（`GuideCard.show → removeAllViews → requestLayout` 栈，`Process com.sofatype.ime has died`，launcher 浮出）。修复：stopNow / startInternal 内 UI 回调一律 `mainHandler.post`；复验 0 FATAL、键盘回位。教训：回调线程契约（「回调保证在主线程」）随宿主线程变化重查所有 invoke 点。
2. **WS onerror 与 onclose 双事件文案覆盖**：WS 升级失败两事件先后触发，onclose 未配对分支把 onerror 已设置的 FR-C8 完整引导覆盖成短句；修正为两处统一使用同一 FR-C8 全文（最终文案确定，不随事件顺序漂移）。
3. **state.url 绝对地址跨源**：服务端下发的配对地址含 TV 绑定 IP，手机若经别名主机访问（走查 redir 回环 / 真实场景主机名），`history.replaceState(绝对地址)` 跨源抛 SecurityException；页面改为只取 url 中 token、按页面自身 origin 拼查询串原位替换（走查实测发现后修正，B1 DOM 断言通过）。
4. **模拟器 `adb emu redir del` 语法与 add 不对称**（模拟器 37.2.13 实测）：add 为 `tcp:<host>:<guest>`，del 只收单参数 `tcp:<port>`——两参数报 `bad redirection format`（T35 坑 1 记录的两参数口径与本轮实测不符，**DEV-GUIDE 修正需求已报 lead**，local/ 目录 dev 不动）。
5. **模拟器进程日志接 `| head` 管道会被 SIGPIPE 杀掉**：`nix run .#tv-emulator | head -N` 在 head 计满后关闭管道，emulator 进程随之退出（本轮模拟器两次「启动后消失」的根因）；模拟器日志一律重定向文件。
6. **debug 包进程终止用 `run-as kill`**：shell uid 无权 `kill` 应用进程；`adb root` 被拒（production build）时，`adb shell run-as com.sofatype.ime kill <pid>` 可达成进程级终止且不触发 force-stop 的「默认输入法打回 Gboard」副作用（坑清单模拟器 6 口径的规避路径）。
7. **R2 · onclose 分支推导会覆盖「已收到明确通知」的文案**：Round 1 把 onclose 的 gotState 分支改为无条件 `setDisconnected()`，被拒路径（connected:false 同样置 gotState）与 network-rebuild 路径的既定文案先后被覆盖（QA qa-10 复现前者，network-rebuild 为 R2 自测发现同族问题）。修复范式：每条「已明确通知」的成因各置独立标记（rejected / exited / replaced / networkChanged），onclose 仅在「无任何明确通知」时才推导断连文案。教训：多成因共用一个布尔（gotState）推导终态文案，必然互相覆盖。
8. **R2 · 模拟器重建后新端口必须重加 redir**：服务重建换随机端口后，旧 redir 不覆盖新端口，探针 / 浏览器全部连接被拒（Connection refused / 浏览器错误页）——与「token 被拒」表象相似，先以 curl 验可达性再查协议（坑 4 同族口径）；另浏览器错误页 tab 在 redir 补上后会自动重载抢消费 token，补 redir 前先 /json/close 清 tab（坑清单模拟器 16 复踩）。
