## 目标

跨屏输入服务基座可用：局域网内可打开 H5 页面并建立 WS 通道。服务随远程模式启停，退出无端口残留。

## 改动

- 新增 `app/src/main/java/com/sofatype/ime/remote/`（7 文件，纯 Kotlin/JVM，无 android 依赖）：
  `Base64Codec.kt`（RFC 4648 编码，minSdk 23 下替代 java.util.Base64）、`BindAddress.kt`（默认路由 IPv4 选取，决策 16）、
  `WsFrame.kt`（RFC 6455 帧编解码 + 分片聚合）、`WsHandshake.kt`（101 握手）、
  `HttpExchange.kt`（请求解析 / 路由 / 占位页）、`RemoteInputServer.kt`（服务生命周期 + HTTP/WS 单端口）、
  `RemoteInputServerManager.kt`（启停入口，BuildConfig.DEBUG 门控，地址收集）。
- 新增 `app/src/debug/AndroidManifest.xml` + `app/src/debug/java/com/sofatype/ime/remote/RemoteServerDebugReceiver.kt`：
  debug 构建专有广播接收器（启动 / 停止 / 状态查询），release 合并不含（决策 21 口径）。
- `app/src/main/AndroidManifest.xml`：新增 `INTERNET`、`ACCESS_NETWORK_STATE` 权限（均 normal 级）。
- 新增 `app/src/test/java/com/sofatype/ime/remote/`（7 测试文件，82 用例；评审勘误：交接原写 79，实数 82）：
  Base64CodecTest、BindAddressSelectorTest、HttpRequestParserTest、HttpRouterTest、WsHandshakeTest、
  WsFrameCodecTest、RemoteInputServerLifecycleTest（含 JVM 真实回环套接字：启停、HTTP、WS 回显 / ping / 分片 / 关闭 / 1002 / 1007）。
- `docs/TASKS_20261104.md`：T13 状态 未开工 → 进行中。
- HTTP 路由：`GET /` 下发占位页（正式 H5 随 T15）；`GET /ws` 升级 WebSocket；404 / 405 / 400；HTTP 响应固定 `Connection: close`。
- WS 会话口径：文本 / 二进制消息分片聚合后原样回显（回环验收）；PING 回 PONG；CLOSE 回显状态码；
  未掩码客户端帧关 1002；文本非法 UTF-8 关 1007；帧 / 消息超 1 MiB 关 1009。
- 隐私红线：服务不持久化任何数据；日志只记事件（启动地址、停止、状态），不记内容。

## 原因
PRD 第 7 章传输口径；第 8 章可靠性与禁止事项 3 要求服务随模式启停、端口无残留。

## 踩过的坑

1. API 34 模拟器：新装应用处 stopped 状态且后台应用不可收隐式广播——隐式 action 广播被系统跳过
   （dumpsys 报 `skipped by policy at enqueue: Background execution not allowed`），且无任何报错。
   走查须先 `am start` 一次应用，再用 `-n` 显式组件定向广播。
2. 监听条目呈现在 `/proc/net/tcp6`（IPv4 映射 `::ffff:<ipv4>` 形式），纯 IPv4 `/proc/net/tcp` 表无条目；
   核查「仅监听局域网接口」须按映射形态解读，不能只查 tcp 表。
3. 首轮设备走查暴露：`stop()` 未关闭监听 ServerSocket，accept 线程阻塞在 `accept()` 时仅置标志无法释放端口，
   STOP 后监听仍存活；JVM 单测此路径存在时序侥幸（stop 早于 accept 阻塞时通过）。已修复并补
   「先跑一次请求强制 accept 阻塞、再 stop、断言连接被拒」用例。
4. WS 客户端脚本发分片首帧须清 FIN 位；脚本首版未清，误报服务端不聚合（服务端行为符合 RFC 6455）。
