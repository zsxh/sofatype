## 目标

最小可用输入法闭环：启用 IME 后，焦点处弹出占位键盘、输入 1 个字符、收起。走通「启用 → 唤起 → 输入 → 收起」全链路。

## 改动

- `app/src/main/AndroidManifest.xml`：注册 IME service `SofatypeImeService`——`android:permission="BIND_INPUT_METHOD"`、`android.view.InputMethod` intent-filter、`android.view.im` meta-data 引用 `@xml/method`（T2 预留位自此接入生效）。
- `app/src/main/java/com/sofatype/ime/SofatypeImeService.kt`（新增）：`InputMethodService` 实现。`onCreateInputView` 程序化构建占位键盘（两个键：示例字符键、下屏键，程序化构建无布局文件，T5 重做）；字符键经 `currentInputConnection.commitText` 上屏 1 个字符；下屏键 `requestHideSelf(0)` 收起；覆盖 `onEvaluateFullscreenMode` 恒 false，防 TV 横屏全屏提取模式盖住宿主界面。
- `app/src/main/java/com/sofatype/ime/PlaceholderKeyboard.kt`（新增）：按键 → 动作纯逻辑（`KeyAction.CommitText` / `KeyAction.HideSelf`），不依赖 Android 类。T3 范围内可独立测试的纯逻辑仅此一处，属最小抽取。
- `app/src/test/java/com/sofatype/ime/PlaceholderKeyboardTest.kt`（新增）：JUnit 4 单元测试（不依赖 Android UI 与模拟器），覆盖：字符键提交恰好 1 个字符、下屏键返回收起动作、占位键位集合恰为最小两键。
- `app/build.gradle.kts`：新增 `testImplementation("junit:junit:4.13.2")`（仅 test 作用域，无产品依赖）。
- `app/src/main/res/values/strings.xml`：新增 IME label 与占位键文案 / 无障碍标注字符串。
- `app/src/main/res/values/dimens.xml`：新增占位键盘尺寸 Token（标注占位，T5 真实布局替换）。
- 范围边界：真实键盘布局、候选词、星夜青完整样式属 T5+，均未实现。

## 踩过的坑
1. 同一条 `export` 语句里 `JAVA_TOOL_OPTIONS="-Duser.home=$HOME"` 取到旧 HOME：shell 对整条语句的赋值先全部展开再逐个生效，`$HOME` 展开时新值尚未写入 → `validateSigningDebug` 仍写真实 `~/.android` 失败。须拆两条 export（先 `HOME` 后 `JAVA_TOOL_OPTIONS`），T1 坑 1 的补救命令按此顺序执行。已补 `local/DEV-GUIDE.md` 1.5。
2. `uiautomator dump` 只导出应用窗口，不含 IME 窗口：占位键盘键位坐标不能从 dump 取，用 screencap 截图目测后 `input tap`；dump XML 节点属性顺序 text 在 resource-id/class 之前，按属性名截取时先核对顺序。
