## 目标

远程模式会话全程，「退出远程」按钮焦点保持可触发：手机推送内容上屏后按钮不再丢焦点，直接 OK 一击完整退出远程（FR-B7 链路）；不再依赖「BACK 保活收起 → OK 唤起重入」绕行恢复焦点。2026-11-15 户主拍板修复口径 = **焦点保持**：大字区装载滚动发生后按钮焦点不得被夺走、焦点全程稳定可触发；不采用「装载后焦点回归」口径。

## 改动

2026-11-15 Round 1 按实际实现更新的事实清单：

- `app/src/main/java/com/sofatype/ime/SofatypeImeService.kt`：
  - `renderRemoteText` 大字区装载滚动由 `fullScroll(FOCUS_DOWN)` 改为 `smoothScrollTo` 纯滚动（T15 既有装载滚动路径，滚动目标偏移经 [RemoteTextScrollTarget](../../../app/src/main/java/com/sofatype/ime/remote/RemoteTextScrollTarget.kt) 计算，未溢出归 0 不滚动）：装载滚动不再触碰焦点树，「退出远程」按钮焦点全程保持；滚动保持末尾与光标可见不变（决策 31 口径）。
  - 「退出远程」按钮补焦点 tag（`REMOTE_EXIT_TAG = "remote_exit"`）：ImeKeyTrace 焦点行从此可区分「按钮持焦（`focus=remote_exit`）」与「焦点被滚动容器夺走（`focus=null`）」两种形态；DPAD 路径对该 tag 走格网查表空表 no-op，导航行为无影响。
  - BACK 分流（T74 `RemoteBackPolicy`）与服务链路零改动。
- 新增 `app/src/main/java/com/sofatype/ime/remote/RemoteTextScrollTarget.kt`：装载滚动目标偏移纯模型（纯 Kotlin，无 Android 依赖）——内容超出视口返回差值；未超出 / 恰好占满 / 高度非法（≤ 0）返回 0（不滚动）。
- 测试：新增 `app/src/test/java/com/sofatype/ime/remote/RemoteTextScrollTargetTest.kt`（5 用例）。

## 原因

2026-11-15 T74 dev-review 走查发现（dev 坑 2，review-qa 独立复现）：进入远程后手机首次推送内容即丢焦点（装载滚动 `fullScroll(FOCUS_DOWN)` 夺走按钮焦点，归因对比 qa-focus-1/2），其后 OK 到达 IME 时 `performClick` 无目标（trace `focus=null`）不触发退出——「上屏后直接 OK 退出远程」路径失效；BACK 保活收起 → OK 唤起重入后焦点恢复（T17 路径聚焦退出按钮）。T15 既有代码，非 T74 引入（T74 渲染层零改动）。2026-11-15 户主拍板立项；同日拍板修复口径 = 焦点保持，Round 1 开工实现。

## 踩过的坑

1. **「退出远程」按钮无焦点 tag，trace 焦点行持焦/被夺两形态同显 `focus=null`（2026-11-15 T76 走查发现，对 T74 坑 2 取证口径的补充修正）**：ImeKeyTrace 焦点行读视图 tag，退出按钮旧代码无 tag——持焦时同样打 `focus=null`，与被滚动容器夺走后的 `focus=null` 不可区分；T74 坑 2 引用的 `focus=null` 行单独看不足以定性，当时以截图 qa-focus-1/2 高亮对比补证定性成立（结论不变）。本轮补 `REMOTE_EXIT_TAG` 后持焦 = `focus=remote_exit`，两形态从此可区分，后续同类取证以 tag 形态为准。
2. **模拟器快照损坏冷启 offline（2026-11-15 T76 复现，DEV-GUIDE 既有坑）**：`-no-snapshot` 冷启仍尝试加载 `snapshots/default_boot` 失败（启动日志 `Failed to load snapshot 'default_boot'`、设备卡 offline）→ 按 DEV-GUIDE 1.4 处置：停进程、删快照目录（保留 userdata）、重启，15 秒恢复 `device`。无新信息，未入 DEV-GUIDE。
