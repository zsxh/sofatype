## 目标

跨屏输入入口可用：三步指引、「远程输入」主按钮、连接状态三态可视。

## 改动

2026-11-07 实际执行内容（Round 1，dev）：

**纯模型（无 Android 依赖，单测锁定）**

- 新增 `java/com/sofatype/ime/RemoteUiState.kt`：连接状态机——`RemoteStatus` 三态（NOT_CONNECTED / WAITING_SCAN / CONNECTED）× `RemoteMode`（KEYBOARD / REMOTE）× `RemoteSideCardFace` 三卡面（GUIDE / PAIRING / CONNECTED，决策 32 整卡切换）；`of(serviceRunning, pairingTokenActive, deviceName)` 从 Manager 可观测值单点推导（服务未运行 → 键盘态/未连接/引导卡；运行中 + token 有效 → 远程/等待扫码/配对卡；运行中 + token 已消费 → 远程/已连接/已连接卡面；停止态防御性忽略残留设备名）。
- 新增 `java/com/sofatype/ime/RemoteUiText.kt`：界面文案单一事实源——FR-B1 三步指引 / 按钮下提示逐字原文、FR-B9 状态行文字、FR-B3「实时接收中」「来自 · <设备名>」与底部提示（内层引号随 PRD 原文『上屏』）、画板①⑤ aria 标注；`connectedFaceText` / `connectedFromText` 格式化（决策 34：协议无位置字段，只展示设备名）。

## 踩过的坑

1. **BACK 隐藏键盘后经 DPAD 重聚焦宿主输入框再唤起 IME，初始焦点 post 与窗口焦点竞态**：
   走查中 BACK 收起键盘后按方向键移动宿主焦点，落在输入框时系统自动唤起 sofatype IME，
   `onStartInputView` 的初始焦点 post 抢在窗口可聚焦前执行 → 失效，IME 视图无焦点
   （trace `onKeyDown ... focus=null`，方向键/OK 全部空转）。tap 重聚焦即恢复；
   走查脚本在 BACK 后重 tap 输入框并核对 trace 再继续（坑 15 同族）。
2. **`onStartInputView` 无条件 `refreshCandidatesBar()` 会把远程模式的候选栏重新置 VISIBLE**：
   远程模式下候选栏为空 LinearLayout（26dp），重开后把主卡远程框架整体顶低 26dp
   （状态行位置偏差走查截图实测），且初始焦点 post 落在 GONE 键区全部失效。
   已修：远程模式运行中该分支不重算候选栏、焦点直接落「退出远程」按钮（本轮走查发现、当轮修复复验）。
3. **drawable 创建未挂载**：`bg_step_circle`（序号圆底形）首轮实现只创建了资源、`GuideCard` 装配处
   漏挂 `setBackgroundResource`，序号圆无底无描边；自测走查与截图均未发现（视觉上数字裸排不显突兀），
   R1 评审抽实发现（review-qa 比对画板①）。修正一处装配 + 补截图取证（tv-11/tv-11b）。
   教训：新建 drawable 与消费点应同轮核对引用（grep 资源名可检出未挂载资源）。
4. **AVD 快照损坏复现与恢复**（T14 坑 3 同款，本轮第二次触发）：上轮 `adb emu kill` 后再启动卡
   offline，启动日志 `Failed to load slirp-socket`；按 DEV-GUIDE 口径停进程 → 删
   `.emulator-adbhome/.android/avd/sofatype-tv.avd/snapshots/default_boot/`（保留 userdata）→
   重启 20 秒内恢复 `device`，应用与设置未丢。恢复路径已在 DEV-GUIDE，本轮仅复验有效。
