## 目标

键盘每次弹出（含收起后唤起重弹）的初始焦点落在字母区 [a] 键（现初始焦点为数字列 [1]，digit_1），便于直接开始打字。

## 改动

- `app/src/main/java/com/sofatype/ime/KeyboardLayout.kt`：新增字母键盘初始焦点格位常量 `initialCell = (1, 4)`——字母区首键 [a]（行 1 数字列 1-3 + 列间隔后即 [a]），与 `SymbolsLayout.initialCell` 对称。
- `app/src/main/java/com/sofatype/ime/SofatypeImeService.kt`：字母键盘三处 `FocusNavigator` 构造（字段初始化 / `onCreateInputView` / `rebuildKeys` LETTERS 分支）显式传入 `KeyboardLayout.initialCell`，初始键口径由 digit_1 改为 [a]；符号键盘分支维持 `SymbolsLayout.initialCell`（digit_1）不变。弹出初始焦点路径（`onStartInputView`）与两处「丢失回初始键」回归路径（候选区出层回键盘 `exitCandidatesLayerToKeyboard` / 候选栏隐藏焦点回归 `refocusKeyboardAfterBarHidden`、引导卡主按钮 LEFT 回退 `handleGuideButtonDirection`）均经 `navigator.initialKey()` 取值，随口径自动一致，回归逻辑本身未改。
- `app/src/test/java/com/sofatype/ime/FocusNavigatorTest.kt`：初始焦点断言由 digit_1 改锁 [a]（键 id、格位 (1, 4)、与 `KeyboardLayout.initialCell` 格位一致性）；被测实例改按运行时字母键盘口径构造；文件头注释补 T40 口径。

## 原因

户主 T12 终验拍板（2026-11-08）：键盘弹出焦点应在字母 a——当前初始焦点在数字列 1，距字母区远、观感不佳。
