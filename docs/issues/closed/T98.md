## 背景

2026-11-22 户主会话拍板（claude-design 画布编辑器评论 + 会话聊天）。现状：键面字号（字母/数字 24、功能键 18、空格 18、完成 22）相对 96×64 键帽偏小，视觉不饱满。户主提出按键字体加大、尽量填满键帽。经画布 A/B/C 三方案对比、四轮回调（48 → 36 → 32 → 30）、键内图标加大、分词列对齐修正、四键边距拉齐后，拍板 A 方案（仅放大、不加粗）。设计稿已按 A 方案全量回写 `designs/20261114`（画板 1/2/3/4/10/11/12/13），对比板 A/B/C 已删除；设计侧口径事实源 = 该画布 flat-form 便签。本 issue 落实现侧同步。

## 需求与口径

TV 键盘全部键面文字与键内图标按下表执行。键帽尺寸 96×64、行距 10、焦点 / 触发 / hover 色口径不变。

| 键面元素 | 原值 | 定稿值 |
| --- | --- | --- |
| 字母 / 数字 / 符号键标签 | 24px | 30px |
| 功能键标签（分词 / 返回 / .com 等） | 18px | 24px |
| 三字符标签键（中英、123_!、全/半） | 18px | 20px（拉齐键内左右边距约 24px；功能键存在 24/20 两档） |
| 空格键标签 | 18px | 24px |
| 完成键标签 | 22px | 24px |
| 键内图标（下屏 24 / 删除 26 / 光标箭头 22 / 上档 ⇧ 26） | 各异 | 统一 30px |
| 完成键格位 | left 1278 / 宽 100 | left 1282 / 宽 96（按分词列栅格对齐，右缘齐键盘右边线，左邻键隙 10px） |
| 符号键盘空格键格位 | left 1178 | left 1176（对齐分词列） |

不改：候选栏、跨屏输入副卡、远程模式两板、设置页 / 手机 H5 / 测试打字页 / 日志页。

## 方案评估

实施前预评——影响范围：IME 键面渲染层（键位标签字号、图标尺寸、完成键 / 符号板空格键格位的定义处；开工时回填实际文件清单）。设计事实源 = `designs/20261114`（画板 1/3/12 为三态基准）。回归面：焦点态底色、触发态（中/英、⇧）色与下划线、候选栏排版不得回归；黄金图视觉回归（`KeyboardVisualRegressionTest`）基线须按新键面重录后全量通过。风险：30px 标签在 96×64 键帽内不换行、不截断（设计稿已验版式）；功能键 24/20 两档并存为拍板取舍。
