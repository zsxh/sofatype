## 踩过的坑

1. **`focusableInTouchMode` 键帽首击聚焦不点击**：Android View 在 UP 时若本次触摸拿走了焦点（`focusTaken`）则跳过 performClick。模拟器 tap 走查会大面积「丢键」（3 tap→2 字符）；DPAD/OK 主通道不受影响。走查用 `input keyevent`（导航 21/22/19/20 + OK 23）替代 tap。
2. **模拟器注入通道偶发丢事件**：长会话后 `input keyevent`/`input tap` 均随机丢失（logcat ImeKeyTrace 无到达记录 = 注入层丢失，非 IME 处理丢失）；重启模拟器实例可恢复。T6「偶发焦点卡死」同源现象，焦点轨迹日志是定位手段。
3. CENTER 键宿主竞态（T6 坑 1 延续）：本轮一次 OK 的 commitText 疑似被宿主同拍处理吞掉（纯 keyevent 轮未复现，tap/keyevent 混合轮出现一次）。
