## 目标

键盘交互与键面按 2026-11-13 户主拍板口径落地。交付四部分：

1. **默认态**：字母键盘开机后首次打开 = 中文输入；会话内记住上次中/英（FR-A13 记忆保留，默认值定为中文，两者并存口径见改动⑤a）。
2. **模式键位**：中文态无[⇧]键，该键位为「分词」键；英文态默认小写、键面随大小写输出状态（小写态键面小写、大写态键面大写），[⇧] 切换（触发态样式不变，决策 47-①）。
3. **符号键盘入口**：[123_!] 进入角态随入口模式（中文 → 全角、英文 → 半角）；手动[全/半]仅本次停留生效。
4. **候选栏单行**：废止「更多 ⌄」展开，行内左右翻页；焦点底色加深。

## 原因

户主 2026-11-13 真机使用反馈与拍板：旧默认态（英文 + 大写）与 TV 中文为主的使用习惯不符；候选「更多」二级展开操作路径长；焦点淡青底与键帽区分度不足。本次会话内逐条确认 8 项细节口径（翻页箭头装饰暗示不进焦点链、翻页后焦点落页首第一候选、空格选当前页第一候选、记忆 + 开机默认中文、分词键三细节、英文撇号走符号键盘半角 R2C3/C4、角态不记忆重新跟随、键面翻转与布局跳动接受）。
