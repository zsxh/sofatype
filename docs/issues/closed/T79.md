## 目标

release 构建下：

1. 远程输入（跨屏输入 P0）可用——[远程输入] OK 确认键正常进入远程模式、出二维码，全链路（配对 / H5 打字 / 上屏 / 断连 / 保活）与 debug 构建一致。
2. 测试打字页有输入框——三件套（测试输入框、填入示例文本、全选）正常显示可用，修复「入口在、页空」。
3. 服务启动失败有用户可见反馈（Toast），不再静默无响应。

## 改动（按实际实现，10 个 app/ 文件）

## 原因

2026-11-16 户主 release 真机（MiTV4）实测反馈两个问题：①[远程输入] 确认键按下无反应；②测试打字页空白无输入框。lead 定位：两者均为决策 21「debug 门控」口径的既定行为、非 release 构建回归——远程服务启动入口自 T13 起按「决策 21 口径延伸」整链门控（T73 曾验证该门控生效为预期），失败仅写 trace（release 默认静默）；测试打字页三件套沿 FR-D1 细项 4 debug 门控（入口按钮不门控，故 release 进得去但页空）。跨屏输入是 P0 产品功能，release 整链禁用且无反馈，产品上不成立。户主拍板：远程输入放开 release + 测试打字页 release 同样显示输入框（决策 65 入册）；当日立项、批准开工、验收归档。
