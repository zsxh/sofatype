## 背景

2026-11-24 户主会话拍板（T103 真机批次失败态复盘后三点拍板）：①代理开关保持开关形态，开启后按顺序尝试 gh-proxy.com → v6.gh-proxy.org → 直连（顺序回退链）；②连接/读超时加大（10s/15s 对跨境 TCP+TLS 握手偏短）；③更新状态不要与按钮挤在同一行，换行独立显示并以 Toast 消息提示。前情：T103 真机批次实测本宽带对 github.com:443 与 gh-proxy.com:443 的 TCP 连接 10s 超时（ICMP 通、延迟正常，属跨境限断/间歇形态），且 gh-proxy.com 为知名代理域存在按域名过滤的可能，v6.gh-proxy.org 为不同域名的同族服务（实测双路径全通过）。

## 需求与口径

1. **顺序回退链**：`UpdateCheck.check` 接受候选列表，按序尝试，任一候选成功（解析出 release）即返回；全部失败返回最后一个失败态（失败语义 EMPTY_ENDPOINT / CHECK_NETWORK / CHECK_HTTP / PARSE / NO_APK_ASSET 不变）。代理开（默认）候选 = [gh-proxy.com 前缀, v6.gh-proxy.org 前缀, 直连]（Atom 源）；代理关 = [直连]；debug 注入 = [mock JSON 源]（UpdateMockReceiver 通道不变）。
2. **超时**：UpdateHttp 连接超时 10s → 30s、读超时 15s → 30s（下载与检查共用）。
3. **UI**：status_row（状态点 + 状态文字）从检查按钮所在水平行移出，换行为独立行；检查三态（已是最新 / 发现新版 / 检查失败）以 Toast 长提示同步弹出；按钮与代理复选框行不再承载状态内容。后续户主二次调整：状态回归检查更新行**行尾**（dot + 文字，不另起行），检查失败与三态仍以 Toast 弹出；代理改独立行「[启用代理] 按钮 + 域名小字 + 行末开/关状态点」。
4. **逐次日志**：每次候选尝试写 `手动检查请求 url=…`（UPDATE_LOG_TAG），发起日志含候选数；取证口径沿 T50 R2。
5. mock 与 debug 注入通道、版本判定、下载与安装链零改动。

## 方案评估

预评（实施前）：

- 影响范围：UpdateCheck / UpdateEndpoint / UpdateHttp（超时常量）/ SettingsActivity / activity_settings.xml / strings / 三个单测文件；mock 与 androidTest harness 零改动（setDebugOverride 默认 JSON 模式签名不变）。
- 回归面：debug mock 走查链不回归（单候选 JSON）；失败态语义与 UI 状态机不变；下载链自动受益于新超时。
- 风险与取舍：代理开时最坏情况 = 前两个候选各 30s 超时 + 第三候选成功，检查总时长上限约 90s（CHECKING 态有进度提示，手动低频可接受）；Toast 在 TV 端为长时长显示。

实施后回填实际改动清单：

- `UpdateCheck.kt`（候选列表 + 顺序回退链；atom 候选检查请求与构造下载地址均应用代理前缀）
- `UpdateEndpoint.kt`（candidates() 回退链展开：gh-proxy.com → v6.gh-proxy.org → 直连；代理开关 SharedPreferences 默认开）
- `UpdateHttp.kt`（连接/读超时 10s/15s → 30s/30s）
- `SettingsActivity.kt`（检查调用候选化、逐候选日志、检查三态与失败 Toast、启用代理行绑定与刷新）
- `activity_settings.xml`（status_row 回归检查更新行行尾；新增启用代理独立行：行首按钮 + 代理域名小字 + 行末开/关状态）
- `values/strings.xml`（update_atom_url 真实源、启用代理行文案、Toast 文案）
- 单测：UpdateCheckTest 配置化重写 + 回退链三用例 + 代理前缀双断言；ManualCheckLogTest / UpdateSettingsChainIntegrationTest 随签名对齐

## 验收

- 单测：回退链用例（首个候选失败 → 次选成功；全失败 → 末次原因；空候选 → EMPTY_ENDPOINT）、Atom/JSON 双形状不回归、链路集成测试随签名对齐，app 单测全量绿。
- **模拟器端到端（2026-11-24）**：回退链实跑（candidates=3 逐候选请求日志；当期网络首候选 gh-proxy 即成功 → UP_TO_DATE）；UI 新布局截图留证（状态行行尾、开关独立行、Toast 呈现）。

- 户主结论：2026-11-24 会话三点拍板实施，真机真网验证通过，归档。
