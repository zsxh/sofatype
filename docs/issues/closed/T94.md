## 背景

2026-11-22 户主会话拍板（调研对齐三轮后拍板，拍板点记录见「需求与口径」）。

现状：主词库为 AOSP 谷歌拼音词库 65 105 条（决策 28/29），内容约十年前冻结。词库外的新词、网络热词、新剧名打拼音为零候选。基线曾排除「云候选 / 联想」（`docs/PRD_20261104.md` 1.4，批次 20261118）。户主重新拍板：采用「词包插件」形态支持词库外热词/新词，排除云候选路线。

## 需求与口径

1. 功能范围：打拼音、简拼、混合缩写时，候选可包含词包中的词库外词。候选装载仍仅由中文组合态触发（决策 42 不变）。上屏后下一词联想仍不在范围。
2. 词包定性：纯数据包，非代码插件。词包 = SPD1 二进制（复用现有 `DictFormat` 格式）+ manifest JSON（名称 / 版本号 / sha256 / 字节数 / 下载地址）。
3. 分发位置（拍板 2）：GitHub Release。下载 URL 构建期写死，用户不可配置。集成测试通道走 mock 参数化（沿 T90 口径），不改正式值。
4. 第三方服务例外（拍板 1）：GitHub（Release 与后续 Actions 流水线）作为第三方服务例外入册，沿 ZXing / Timber 先例（户主明确指令）。流水线侧见 T95。
5. 更新时机（拍板 3）：设置页词库子页手动点「更新 / 下载」。自动更新不做。
6. 设置页新增「词库」子项：词包列表（名称 / 版本 / 大小）、勾选开关、手动更新、下载进度、失败可重试。
7. 下载与校验：下载落应用私有目录 `filesDir/dicts/`。sha256 校验通过才启用。校验或加载失败回退纯主词库，输入主链路零影响（对应基线「崩溃不阻塞宿主」）。
8. 引擎合并：勾选集合变化时，主词库 + 勾选词包合并重建引擎。词包词频加权提升，保证词包词可进入候选前列。
9. 隐私红线：下载为匿名 GET，不带设备唯一标识、不带任何用户输入内容。词包是应用分发的数据，非用户输入，可持久化；卸载随应用目录清除。
10. 基线修订（新压旧）：`docs/PRD_20261104.md` 1.4「云端账号、云词库同步（本期输入全部本地/局域网完成）」修订为「输入处理全本地 / 局域网；词包等资源管理可联网至构建期固定的分发位置」。1.4「云候选 / 联想」排除条款边界澄清：词包为显式下载的离线数据包，运行时无云端补词，不属云候选；「联想（上屏后下一词）」排除不变。
11. 主词库机制不动：决策 28/29（词库源入库 + sha256 + 构建零网络）不变。构建零网络指 APK 构建期；词包下载是运行时用户显式操作。

## 方案评估

实施前预评：

- 影响模块：`:pinyin`（多词包 DictData 合并加载入口导出）；`:app`（引擎装载点、设置页新子页、设置页焦点路由扩展、下载器复用 UpdateHttp 自研 HTTP 模式：专用线程、不落主线程、StrictMode 坑 14 口径）。
- 词包原料与预处理（scel 转换、热搜筛词注音）在构建机完成。本 issue 只用手动产出的 1 个样例词包（建议 scel「新词热词」类）+ 固定 GitHub Release URL 验证闭环。流水线自动化另立 T95。
- 回归面：中文候选刷新 ≤ 200 ms（`docs/PRD_20261104.md` 第 8 章）须复测；零词包勾选时行为与现状完全一致；设置页焦点导航不回归。
- 风险与取舍：词包词频权重过高会挤掉常用词，权重系数留拍板空间；GitHub 国内可达性不稳，靠手动时机 + 失败重试缓解；模拟器只做逻辑回归（坑清单口径），下载链路真机验证另提请。
