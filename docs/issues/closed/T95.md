## 背景

2026-11-22 户主会话拍板，与 T94 同日同源。T94 拍板词包插件机制并把 GitHub（Release + Actions）定为第三方服务例外。T94 用手动样例词包验证机制；本 issue 把词包生产自动化。

## 需求与口径

1. 流水线产出：从原词库预处理为 SPD1 词包 + manifest（名称 / 版本 / sha256 / 字节数 / 下载地址），发布至 T94 构建期固定的 GitHub Release。
2. 原料两路：搜狗细胞词库分类词库（scel，内嵌拼音表，免注音）；热搜筛词（人工每周筛 20~50 词，pypinyin（MIT）注音，查主词库去重）。
3. 流水线宿主：GitHub Actions 免费档定时触发；保留本机手动触发兜底。定时周期待拍板，建议周级。
4. 搜狗细胞词库版权口径：官方条款限个人使用，社区共识勿商用。户主拍板：私人家用使用接受（2026-11-22），产物不对外分发。
5. 转换器为构建机工具，不进 APK；新工具先进 `flake.nix` 再用（工具链铁律）。
6. 确定性：转换可重跑字节稳定（沿 `VerifyDict` 确定性口径），产物 sha256 写入 manifest。
7. 词包版本号带日期（建议 YYYYMMDD.N），TV 端按 manifest 版本判定更新。

## 方案评估

实施前预评：

- 影响模块：`:pinyin` tools（新增 scel → SPD1 转换器，沿 `ConvertDict` / `DictBuilder` 模式）；仓库新增流水线配置与词包发布脚本。
- 回归面：主词库 `ConvertDict` / `VerifyDict` / sha256 门禁零改动；`:pinyin` 主构建零网络不变（流水线是独立工具链路）。
- 风险与取舍：scel 格式无官方文档，解析按开源解析器（scel2txt 等）对照，需抽样核对转换正确性；GitHub Actions 免费额度依赖仓库公开性；热搜接口无 SLA，挂了换源。

## 验收

口径清单（执行后补结果）：

- 流水线完整跑通一次：原料 → SPD1 词包 + manifest → 发布 GitHub Release。

- 确定性验证：同原料重跑流水线，产物 sha256 一致。
  - 结果（2026-11-22 Round 1）：通过。review-qa 亲测两轮重跑 + dev 首跑，三方 sha256 完全一致；wordPackBuild 每轮实跑非 up-to-date，verifyDict sha256 门禁先于转换执行。

  - 结果（2026-11-22 Round 1）：通过。review-qa 以独立 Python 解码器对照：scel 抽 20 词词条/拼音/词频 0 不一致；热搜 30 源行全量对照 0 不一致（12 条去重分类核验全部吻合去重口径）。
