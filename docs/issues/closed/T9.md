## 目标

本地拼音引擎可用：拼音串切分组合出词组级候选并排序。无网络依赖，单测可独立验证。

## 改动

- 新建纯 Kotlin JVM 模块 `:pinyin`（目录 `pinyin/`），不依赖 Android 与任何第三方库，只依赖 Kotlin stdlib：
  - `DictData` / `DictFormat`：词库内存结构与自有精简格式 SPD1 的读写；
  - `PinyinSegmenter`：拼音切分器，音节表取自词库数据（416 个无调音节），输出全部切分方案与首音节集合；
  - `PinyinEngine`：查询引擎，词条全拼字母级前缀匹配（整词 + 组合态增量），候选按词库内建频次降序、同频按源行序稳定，同词多读音去重取最高频次，单字词兜底由词库 17 037 条单字词条覆盖；
  - `tools/DictBuilder`：AOSP 词库源文本（UTF-16，每行「词 频次 标志 逐字拼音…」）解析，含合规校验与跳过计数；
  - `tools/FetchDict` / `tools/ConvertDict`：源文件获取（GitHub 镜像优先、AOSP 官方源兜底、已存在则跳过）与构建期转换入口。
- Gradle 任务：`:pinyin:fetchDict` / `:pinyin:convertDict`（含输入输出声明，幂等 up-to-date）/ `:pinyin:buildDict`；`:pinyin:processResources` 依赖 `buildDict`，构建自动完成转换。
- 入包接线：`app/build.gradle.kts` 的 assets 源目录指向 `pinyin/assets/`，APK 内置 `assets/dict/pinyin_dict.bin`（决策 28：原始源文件不入库，产物入包）。
- 工程接线：`settings.gradle.kts` 增加 `:pinyin`；根 `build.gradle.kts` 声明 `org.jetbrains.kotlin.jvm` 1.9.24；`.gitignore` 增加 `pinyin/dictsrc/` 与 `pinyin/assets/dict/`。
- 新建仓库根 `NOTICE`：注明词库来源（AOSP PinyinIME `jni/data/rawdict_utf16_65105_freq.txt`）与 Apache-2.0 许可。
- 单测：`pinyin/src/test/kotlin/` 下 5 个测试类 38 个用例（切分 / 格式读写 / 源解析 / 引擎查询 / 真实词库与性能量级）。
- 未接 UI：InputMethodService / 候选栏接入属 T10，本任务未动 `app` 源码逻辑。

## 原因
FR-A8 本地引擎无网络依赖；引擎选型已拍板（自研词组级 + 开源词库）；独立模块可先于 UI 用单测验证。2026-11-06 户主拍板换源（决策 28）：CC-CEDICT 无词频、排序无依据，且实际许可为 CC BY-SA 4.0；AOSP 词库词频内建、逐字拼音齐全、Apache-2.0 最宽松。

## 踩过的坑
1. SPD1 音节 id 初版按 uint8 存储，源库音节池 416 个，id ≥ 256 被 `writeByte` 高位静默截断（如 ting=333 → dun=77），查询结果错误且读写端均不报错。修复：音节 id 改 uint16 存储，读端保留 id 越界校验。
2. 同一轮 Gradle 构建中 `processResources` 与 `convertDict` 无任务依赖边，执行顺序不定，测试可能复制到旧产物。修复：`processResources` 显式依赖 `buildDict`；`fetchDict` / `convertDict` 声明输入输出后幂等。连带坑：JavaExec 任务 classpath 若用 `runtimeClasspath` 会经 processResources 与 `buildDict` 成循环依赖，改用 `compileClasspath + classesDirs`（不含 resources）。
3. 源词库每行第 3 列为标志字段，语义无官方文档确认（镜像仓库无对应解析文档），转换时忽略；该字段不影响词 / 频次 / 拼音三要素，已在交接包显式标注。
