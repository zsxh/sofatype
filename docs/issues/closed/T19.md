## 条件分支如实标注

① 端到端时延的「iPhone 触屏 → WS 发出」段无仪表（无录屏，户主拍板），客观 RTT 为 Mac 浏览器驱动端口径，主体感为主判据。② 扫码 3s 无手机侧计时，体感+TV 端点佐证。③ 安卓 Chrome 不可测（户主仅一台 iPhone）；户主 2026-11-08 拍板不另行安排。④ IP 变化真机免除（户主拍板）；真机触发通道实测：`svc wifi` → SecurityException（shell 无 CHANGE_WIFI_STATE，logcat 18:41:41.918）；`svc airplane` → Android 6 无此子命令；`settings put global airplane_mode_on` + 广播 → 设置位生效但 MiTV Wi-Fi 栈不响应（wlan0 未掉线）。换网段子分支（onLinkPropertiesChanged 换段比对）：代码在、无运行时证据（模拟器不可构造、真机触发通道如前全堵）；户主 2026-11-08 拍板不测（不补测、不补 JVM 单测）。⑤ commit 失败分支真机构造不可达（触摸模式焦点语义 + 平台清杀），JVM 口径维持。⑥ tv-exit H5 渲染见证触发源为 commit teardown 而非手动 BACK（同一 disconnect 帧/同一 T18 stop 编排）。⑦ 户主转述 tv-exit 文案「远程连接」与设计逐字「远程输入」一字差，未逐字核对，不作判定依据。⑧ 扫码/打字走查期间电视平台两次静默清杀应用进程（屏保启动强杀 + MemoryAutoClean），均按恢复口径处置，相关时轴在案，未影响证据有效性。
