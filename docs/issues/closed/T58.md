## 目标

符号键盘半角布局（户主称「半符号」）下，焦点可在 [0] 与 [*] 两键位间经左 / 右方向键直接移动，不再绕路或跳走。

## 改动

2026-11-12 实现完成（模拟器已验证；真机复验经户主拍板并入真机批次）。

- 根因定位（模型层格位推导 + 代码核对）：半角符号行 4 格位为 [0]（col1）+ 空格位（EmptyCell，col2/3，决策 27 移除 .com/@ 后保留键宽占位）+ 7 符号（col4-10）。FocusNavigator.next 旧实现按「相邻格位」单步寻路，[0] RIGHT 目标格 (4,2) 与 [*] LEFT 目标格 (4,3) 均为无键空格位 → 返回 null → 服务层保持焦点不动。
- 改动文件（2 个源文件 + 2 个测试文件）：
  - `app/src/main/java/com/sofatype/ime/FocusNavigator.kt`：next 由「相邻格位单步」改为「该行 / 列线最近实键」寻路——空格位越空直达、不越任何实键；扫到自身占据格位（跨行键另一格）即停不动；表缘不动语义不变。新增格网规模常量 GRID_ROWS/GRID_COLS（4×12）。文件头导航规则注释与 EmptyCell 行注释同步更新。
