## 踩过的坑
1. targetSdk 34 运行时 `registerReceiver` 必须显式 RECEIVER_NOT_EXPORTED/EXPORTED 标志，缺省抛 SecurityException 直接崩设置页（模拟器实测，Android 14 强制）；4 参重载 API 26 起可用，加版本门。
2. PackageInstaller 回执 PendingIntent 必须 `FLAG_MUTABLE`（API 31+）：immutable 拦掉系统 fill-in，回执变无 extras 空广播（实测连续两次空回执误判失败/待确认）；FLAG_MUTABLE 常量 API 31 起，低版本直接 UPDATE_CURRENT。
3. Android 14 TV 系统安装器不自弹确认框：回执 status=PENDING_USER_ACTION(-1) 时确认框 Intent 在 `EXTRA_INTENT`，应用须自行 startActivity 转交。
4. GMS TV 系统安装器（InstallStart）要求调用方清单声明 `REQUEST_INSTALL_PACKAGES`，否则拒绝受理（logcat 实证 "needs to declare permission"）。
5. 安装替换进程被杀 → 默认输入法回退 + 系统弹「键盘设置」页压前台（T39 评估场景模拟器复现）；`ime set` 恢复。
