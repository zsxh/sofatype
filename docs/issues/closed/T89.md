## 背景

2026-11-19，户主直接指令（会话明示「将 apk 版本提高到 0.2.0」）。首版 0.1.0(1) 已随 T1~T88 收口（`docs/PRD_20261104.md` 第 12 章决策 38）；版本按决策 19「随发布批次递增」升至 0.2.0(2)。

## 需求与口径

1. `app/build.gradle.kts` defaultConfig：`versionName = "0.2.0"`、`versionCode = 2`。
2. 版本递增遵循 `docs/PRD_20261104.md` 决策 19 口径（versionName / versionCode 以构建配置为准，随发布批次递增）；设置页版本行仍只展示 `v<versionName>`（决策 40 不变，versionCode 不对用户展示）。
3. 本 issue 只做版本号递增：不改运行时代码、不改第三方依赖、不做发版动作（`CHANGELOG.md` 一版一节在发版时更新）。

## 方案评估

- 影响范围：仅 `app/build.gradle.kts` defaultConfig 两个常量。运行时版本展示（`VersionFormatter` / `SettingsActivity`）与升级判定链（`UiInstallOutcome`）均从 PackageManager 读值，自动跟随，无需改码。
- 回归面：相关单测（VersionFormatterTest / UpdateCheckTest / UpdateVersionTest / UiInstallOutcomeTest）断言均用字面量 fixture，与构建版本无耦合，不受影响；「检查更新」判定逻辑不变。
- 风险与连带（已知，不在本 issue 处理）：`tools/mock/github-releases/` mock 源锚定旧基线 0.1.0(1)——版本升后 `releases-newer.json`（tag v0.2.0）与当前版本相等，会落「已是最新」而非「发现新版」，其 APK 资产 0.2.0(2) 与工程同版本，不再满足「versionCode 真递增」验收口径。下次检查更新走查前需另立 issue 整体刷新 mock 资产（如 newer → v0.3.0(3) 并重制递增包），届时连同其 README 口径一并修订。

实际改动清单（2026-11-19 实施）：

- `app/build.gradle.kts`：defaultConfig `versionCode` 1→2、`versionName` "0.1.0"→"0.2.0"，注释同步当前版本值
- `docs/issues/NEXT-ID.md`：取号回写（下一编号 T90）
- `docs/issues/open/T89.md`：本 issue 建档
- `docs/HANDOFF.md`：当前快照工程基线版本值更新为 0.2.0(2)；决策速查表登记 T89 一行

## 验收

- 构建验证：`nix develop` 沙箱按 `local/DEV-GUIDE.md` 2.3 模板执行 `./gradlew --no-daemon assembleDebug` 成功；产物 `app-debug.apk` 经 `aapt dump badging` 核对 `versionName='0.2.0' versionCode='2'`。
- 真机装机不在本 issue 范围（纯构建常量，无运行时行为变化）；下次发版批次装机时随包核验。
- 区分口径：本 issue 验收 = 构建已验证；真机未验证。

结果（2026-11-19，构建已验证）：

- `nix develop` 沙箱按 `local/DEV-GUIDE.md` 2.3 四件套重定向执行 `./gradlew --no-daemon assembleDebug`：BUILD SUCCESSFUL（15 s，41 任务，15 executed）。
- 产物 `app/build/outputs/apk/debug/app-debug.apk`（3 279 032 字节，2026-11-19 16:01）经 aapt（build-tools 34.0.0）`dump badging` 核对：`name='com.sofatype.ime' versionCode='2' versionName='0.2.0'`，与口径一致。
- 证据备注：aapt 不在 devShell PATH，实测位于组合 SDK 镜像 `android-sdk-build-tools-34.0.0/libexec/android-sdk/build-tools/34.0.0/aapt`（HANDOFF 坑 4 同族，组合镜像符号链接目录下 nesting 一层）。

户主结论（2026-11-19）：纯构建常量免真机验证，拍板通过，当日归档。
