## 踩过的坑

1. 切换默认输入法会被系统自动夺回：`ime set` sofatype 后弹出搜狗崩溃反馈弹窗（搜狗进程被切走时异常），系统随后把 `default_input_method` 自动切回搜狗——表现为「ime set 已 selected，弹出键盘却是搜狗」。处置：重新 `ime set` 后立即走查即恢复；走查期间每次弹键盘前先 `settings get secure default_input_method` 核对。搜狗异常反馈弹窗用 BACK 关闭（不点发送）。
2. 根 Activity 上 BACK 的时序差异：`am start` 后键盘自动弹出立即 BACK，设置页直接退出（回到信号源页）；键盘经用户操作（DPAD）唤起后 BACK 则只收起 IME、Activity 保留。走查统一用「DPAD 唤起 → BACK 收起」路径验证。
3. 电视无触摸屏，`adb input tap` 注入仍生效（下屏键 tap 1268,626 收起成功）——遥控器 DPAD 与 tap 两条路径在 MiTV4 上均可用。
4. 屏保抢占走查（评审补记）：走查间隔电视空闲会自动进 `com.mitv.screensaver`，设置页被压后 tap 全落空、uiautomator dump 全是屏保节点。真机走查须连贯执行，或唤醒后确认前台再操作（`dumpsys window` 核对当前前台）。
