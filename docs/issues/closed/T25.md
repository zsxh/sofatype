## 目标

远程模式不空转：空闲 30 分钟自动退出并收起键盘。

## 改动

（2026-11-09 dev 实现后更新）

- 新增 `app/src/main/java/com/sofatype/ime/remote/RemoteIdlePolicy.kt`：空闲退出判定纯模型（不依赖 Android 类，时间由调用方注入）。正式阈值常量 `DEFAULT_IDLE_TIMEOUT_MS` = 30 分钟（PRD 第 8 章口径）；空闲窗口进入 / 解除 / 重进刷新三个状态转移 + `shouldExit(now)` 边界判定。
- 新增 `app/src/test/java/com/sofatype/ime/remote/RemoteIdlePolicyTest.kt`：9 例——正式阈值 = 1 800 000ms、未进窗恒不退、阈值前一刻/整点/之后边界、连接解除后不退、解除后保持、断连重进从新起点起算、重复进入刷新起点、非法阈值拒绝构造。
- `app/src/main/java/com/sofatype/ime/remote/RemoteInputServerManager.kt` 接线：
  - 服务启动成功与已配对连接断开（回等待扫码）两处起算空闲窗口（`armIdleExit`，主线程排程）；手机配对成功（`onPaired`）与停服清理（`stopNow`）两处解除（`cancelIdleExit`）。
  - 到期复核（运行态 + 无已配对会话 + 窗口判定）命中后走 `stop()` 既有完整清理链路（通知手机 / 关监听 / 清 token·缓冲·设备名）。
  - 新增 `onRemoteIdleExpired` 回调（主线程契约，生命周期同既有回调），空闲退出后通知 IME 收起键盘。
- `app/src/main/java/com/sofatype/ime/SofatypeImeService.kt` 接线：`onCreateInputView` 注册 `onRemoteIdleExpired` → `requestHideSelf(0)` 收起键盘窗口（`onDestroy` 解除）。
- 验证口径：模拟器走查用临时缩短阈值（60s）重建 debug 包，走查完成后恢复 30 分钟并重新全量构建；最终代码与构建产物不残留缩短值。

边界如实标注：

- 正式 30 分钟阈值未在模拟器等待验证（验证口径 = 缩短阈值 60s，TASKS T25 验收方式原文）；30 分钟数值由单测常量断言锁定。
- 场景 2 的「手机」为本机 python3 标准库 WS 探针（`adb emu redir` 通道），非真实手机 H5 页；配对链路（hello → state + 滚动签发）与真实手机同路径。
- 「远程输入缓冲清空」本轮未单独构造非空缓冲场景（场景 1/3 走查时缓冲本为空）；清空动作在既有 stop 链路内（T18 已验证语义，本任务未改动该链路），走查日志可见停服链路完整执行。
- 走查通道清理：redir 已删、logcat 探针进程已清、模拟器 `adb emu kill` 优雅退出（无设备残留、无 qemu 进程）。

真机维度：未验证（本任务模拟器口径，同 T23/T24 拍板；验收方式未要求真机）。
