### 1.1 FR-E1 细项

1. 匹配口径：词条首字母串 = 各音节首字母拼接（如 [zhong, guo] → zg），与输入做前缀匹配；查询双路并行——全拼前缀路（FR-A8 现行口径不动）+ 简拼前缀路。
2. 合并排序：输入 ≥ 2 字母时全拼命中排前、简拼命中按内建频次排后，词 id 去重；单字母输入取简拼路结果（实测为全拼路超集），按内建频次统一排序。
3. 词库与格式：SPD1 词库格式与文件不变，首字母串运行时派生（加载时从既有音节 id 派生 + 建首字母倒排桶）；实测不达标再评估预置进格式升级。
4. 单字母边界：i / u / v 无候选属拼音体系限制（汉语拼音无以这三字母开头的音节），不判缺陷；其余 23 键单字母即出高频词（实测 z → 在 / 这个 / 中，n → 你 / 那 / 呢）。
5. 空格键：决策 8 R-2 语义不变；首键即有候选后，组合态空格恒为「上屏首候选」，「无候选输入空格」仅在无命中串（含 i / u / v、乱串）时触发。
6. 上层不动：ChineseComposer / SofatypeImeService / 候选栏（20 条 + 翻页）复用现状，零改动。
7. 无障碍与性能预算：沿用上游批次口径；中文候选刷新 ≤ 200ms 以真机实测为准。

## 2. 非目标（本批次不做）

- 混合缩写（逐音节「全拼 / 缩写」混排，如 zguo → 中国、srf → 输入法、zhly 声母形态）：二期记录 T84，本批次不实现（决策 D3）。
- 声母简拼（zh / ch / sh 整声母缩写）：归入 T84 二期形态，本批次不做。
- 模糊音、双拼、整句输入、云候选 / 联想：延续上游非目标，不做。

## 3. 设计依据（立项调研数据，2026-11-18）

- 引擎现状：仅「词条全拼串前缀」单路匹配（`PinyinEngine.query`），输入须切出完整合法首音节才进桶；实测 z / zh / zho / zg / nh 全部零候选，打到完整首音节（如 zhong，5 键）才首次出词。
- 词库复算（`pinyin/dictsrc/rawdict_utf16_65105_freq.txt`，65 105 条词条，sha256 锁定）：zg 命中 295 词（这个 253 424 / 中国 106 589 前 2）；bj 命中 226 词（北京第 2）；nh 命中 67 词（你好第 1）；单字母 23/26 键出高频词（z 桶 6 169 词条为最坏扫描量级）。
- 排序可行性：仅凭词库内建频次即可用，无需新增语料或索引结构。

## 4. 验收标准

1. 单测全绿（`--rerun-tasks` 强制实跑口径）：合成词库双路合并去重排序、单字母超集口径、i / u / v 无候选、limit 截断、非法输入空列表；真词库口径断言（zg、bj、单字母 top1、频次组内单调）与查询性能量级复跑。
2. 模拟器（API 34）：中文模式输 zg 出「中国」类候选、单字母即刻出字、全拼查询不回归、空格选首候选与候选翻页正常。
3. 性能：单次查询含简拼路 JVM 量级佐证 + 真机 200ms 预算实测。
4. 真机复验（MiTV4；模拟器验证成功后询问户主是否执行）。
